# A-SPX 相位候选：完整 PCM、包络与相关性验证

日期：2026-11-08；基于 `5786d78` 加前轮未提交的只读观察入口。本轮结论已按
[ADR-0026](decisions/0026-retain-aspx-noise-and-patch-phase.md)采用：保持生产相位，
将固定 R64 差异作为已解释的实现差异记录。生产 DSP、CLI、公共 API 和三层 PCM
基线没有改变。机器记录见
[`aspx_phase_candidate_comparison.json`](experiments/aspx_phase_candidate_comparison.json)。

## 冻结的候选与范围

前轮[分量归因](HF_RESIDUAL_RESERVE_INVESTIGATION.md)在两个窗口分离了噪声和生成信号。
本轮将对应候选放入完整 Full 引擎，只在 `cfg(test)` 中执行：

| 模式 | 噪声 | HF 搬运 |
| --- | --- | --- |
| `baseline` | 原样 | 原样 |
| `noise_inverse_r` | 生成后、组装前乘 `1/R(k)` | 原样 |
| `patch_ratio` | 原样 | HF 生成后、包络估计前乘 `R(p)/R(k)` |
| `noise_and_patch` | 两项同时执行 | 两项同时执行 |

`R(k)=-exp(i*pi*(k+0.5)/128)`，`p/k` 来自实际 patch 表。只旋转已生成的当前区间，
组装后的越帧成品继续由原状态携带。没有改 QMF 两端、音调初相、噪声表、游标或信令。
搬运候选发生在估计之前，包含旋转舍入对后续增益的实际影响；不能描述为固定全部增益。

13 条新码流加 8 条旧输入，共 21 条、4,150 AU，四组共 84 次完整本地解码。旧输入含
纯音／音乐的 limiter 开关、两个额外音调探针和 preflat 单改控制。参考均复用已有
完整、参数一致的捕获；本轮没有增加原生参考覆盖。

沿用完整 raw 输入、显式对象身份、`local_scale=2^-16` 和 31 样本参考延迟。每个默认
输出都经 f32 Scene 单位往返与既有 CLI WAVE 逐位核对；所有候选保持 core PCM、完整
控制／时间记录和 LFE 字节。参考 21 路物理缓冲中的未描述填充路继续要求全零。

## 能量、相关性、瞬态和尾部

每个实际旋转都检查复系数的单位能量误差，预算含 f32 舍入、次正规数绝对误差和固定
f64 余量；84 次解码最大误差／界约 0.7062。相同子带对各声道共用旋转的复积不变量
另有普通测试。这个性质不推出混合信号的有限 PCM 窗口能量相同。

PCM 检查另外统计：

- 256／2048 样本窗口的逐轨能量误差，包括不足一窗的完整尾部。
- 12–18 kHz Hann 窗频带能量及复相干性；这里单列 STFT 未覆盖的尾部样本数。
- 全段未去均值的零延迟归一化互相关；分母为零的路对单独计数，不当成吻合。
- 固定首／末三 AU 的误差、峰值与全段最大相邻采样跳变量，不移动窗口追逐峰值。

例如宽带 L4 448K 的频带能量相对绝对误差由 0.048008 降至 0.007805，HF 复相干性
差异的参考能量加权 RMS 由 0.006462 降至 0.000417。但其全带 2048 样本包络误差
由 0.252040 升至 0.253413；全带仍含参考带宽之外的部分，须和频带指标分开。

瞬态 L4 768K 的频带包络改善，但 HF 相干性加权差异由 0.010331 升至 0.012158，
说明不同指标可以反向。瞬态 L4 1500K 的全段误差增加约 0.099 dB，末三 AU 误差能量
约为默认的 1.0498 倍。没有把这些结果从汇总中删去，也未由数值指标宣称可听收益。

## 生成信号的后续隔离

继续使用旧音乐 preflat 单改控制。实际复核仅 18 个声明位置从 1 改为 0，其他所有
比特和完整 sync-frame 边界不变；core PCM、时间轴、A-JOC 控制相同。参考 PCM 完全
相同。当前解析器在选定窗口确认唯一配置差异为 `preflat`。

在联合相位诊断下，preflat=0 的整段 12–18 kHz 误差相对 preflat=1 再下降约
14.804 dB。为避免把电平联动归给单一 HF 阶段，再于 AU 100 的 9 次调用、23 个包络中
固定同一份本地噪声、音调和注噪条件，分别交换实际 HF 与实际信号增益：

| 局部组合 | 相对原组合的误差能量改善 |
| --- | ---: |
| 只换 HF | −13.694 dB |
| 只换增益 | −17.379 dB |
| HF 与增益同时换，噪声／音调固定 | 5.254 dB |
| 完整 preflat=0，允许其实际电平联动 | 24.626 dB |

原组合按生产的 f32 乘法、条件注噪、再加音调顺序逐位复现。参考使用已有双进程检查点，
并核对到已验证的 A-SPX→矩阵源绑定；不新增参考调用数。差异说明预平坦化、补偿增益
和生成电平是耦合问题，不能把完整旁路的分数当作只删除一个步骤的独立正确性依据。

## 裁决、限制和复现

本轮对[锁定规范](https://www.etsi.org/deliver/etsi_ts/103100_103199/10319001/01.04.01_60/ts_10319001v010401p.pdf)
接口的复核没有找到要求额外旋转的遗漏。独立 FIR／表示不变量和当前公式保持一致，
因此按 ADR-0026 保留生产默认；不继续把已解释的固定相位差当作必须追平的残差。
下一项聚焦预平坦化→增益→噪声电平的耦合及既有宽度响应差异。

本轮只增加测试入口和检查器。无新的 harmonic、活动 FIC/TIC、companding、短帧或
channel-based／IMS PCM 覆盖；也没有普遍误差门限。全部原始材料留在核验 UUID 的
cache 卷，使用既有 Cargo target。前轮源文件及测试可执行文件另有冻结快照。

```bash
MACINAC4_ASPX_PHASE_CANDIDATE=noise_inverse_r \
MACINAC4_AJOC_INPUT_STREAM=/absolute/path/input.ac4 \
MACINAC4_AJOC_INPUT_OUTPUT=/absolute/path/new-output \
MACINAC4_AJOC_INPUT_AUS=2 \
  cargo test -p macindecode-ac4-decode --release --features audio-decode \
  capture_ajoc_input_boundary -- --ignored
python3 scripts/check_aspx_phase_candidate.py MANIFEST --output NEW_REPORT
python3 -m unittest scripts/test_check_aspx_phase_candidate.py
```
