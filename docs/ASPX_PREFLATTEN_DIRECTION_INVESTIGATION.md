# 预平坦化：方向修正与旁路的独立对照

日期：2026-10-17；生产起点 `105b81b`，已包含 ADR-0021 的注噪预算修复。
本轮完成候选验证，生产算法、公开 API、CLI、默认策略和三份 PCM 基线不变。
机器记录见 [`aspx_preflatten_direction_comparison.json`](experiments/aspx_preflatten_direction_comparison.json)。

后续状态：本报告保留调查时的判断和数值。生产已按
[ADR-0022](decisions/0022-correct-aspx-preflatten-gain-direction.md)以独立失败反例为依据修正
P85 差值方向；修复回归和当前生产结果单列，不回写历史实验。

## 结论与建议

**调查目标是证明真实问题及修复依据。** DRP 用于暴露分歧、定位边界和复核现象，其 PCM
差分不作为正确性裁决或候选排序的目标。参考误差降低既不能证明修复正确，升高也不能
单独否定一个有独立依据的修复；每项变化仍须解释其传播和副作用。

已经证实：在零预测项、高能量、可被三阶多项式准确描述的输入上，P85/P89 字面组合会
放大粗谱斜率，与预平坦化目标冲突。当前本地实现忠实执行这组字面，问题应登记为规范
组合与工具目标的冲突，不能仅凭 DRP 旁路就定性成本地漏实现或认定应删除该工具。

方向修正能消除该反例的粗谱斜率，但尚未唯一证明笔误位于 P85 或 P89。
完整旁路只保留为定位对照，不列为本任务待采用的修复或参考兼容策略。

若采用方向修正，建议优先反转 **P85 指数中的差值**，保留正文和 P89 明写的取倒数：

```text
原 P85：gain = 10^((mean_energy - fitted_envelope)/20)
候选 P85：gain = 10^((fitted_envelope - mean_energy)/20)
P89 仍为：filtered_HF /= gain[source_band]
```

直接把 P89 改乘法也能修正方向，数学上等价，但两者的实际 Float32 HF 输出最多差 2 ULP，
不能称逐位相同。选择 P85 差值修正的依据是保留两处一致写明的应用方式，并使整个工具
满足平坦化方向；不是因为它更接近某个参考输出。

这是以平坦化目标为前提的拟议本地判读；“优先”指最小、可解释的修改位置，不是 DRP
得分更高。当前没有官方勘误依据，本轮未将任何候选并入生产默认值。

后续采纳门槛是：从条款和工具目的确定独立性质，构造当前生产违反该性质的最小反例，
让实际生产调用上的回归在旧式失败、修复后通过，再核对零／近零、复杂谱形、TNA、
包络补偿和跨帧状态的边界。现有“两方向可区分”测试仍是调查判据，不冒充这一生产修复回归。

## 原文与数学边界

重新核验锁定的 `TS103190-1:v1.4.1:5.7.6.4.1.1`、`5.7.6.4.1.2`、`5.7.6.4.1.4`，
并目视检查 PDF 第 217、218、220 页。正文明确描述在 patch 时应用增益的倒数，P89 与之
一致；P85 则使用 `mean_energy - slope`。因此不能仅把问题定位成 P89 的一个运算符笔误。

设输入 dB 包络为 `e`，三阶拟合为 `f`，均值为 `m`。功率远高于 `+1` 地板时：

```text
原组合的输出包络 ≈ e + f - m
任一方向修正后   ≈ e - f + m
```

当包络本身是三次以内的多项式，`e≈f`，前者将粗谱形放大，后者变为常量。
这项性质在零预测项控制下成立；真实 TNA 还会改变各子带残差，不能要求任何实际 HF
输出都完全平坦。低能量处 `+1` 地板不可忽略，本轮保留它，不另调尺度或门限。

## 四种诊断变体只改变一个环节

从同一源码起点顺序构建四份本地二进制，复用原 `target`。所有其它生产源码保持冻结，
每份构建均保存实际变更及摘要；候选二进制只留在外置实验目录。

| 名称 | 唯一变化 |
| --- | --- |
| `literal` | 当前 P85/P89 原样 |
| `multiply` | P85 不变，P89 的两次除法改为乘法 |
| `reverse_gain` | P89 不变，P85 指数的差值反向 |
| `bypass` | 不施加 P85 增益；控制数据仍计算和校验 |

没有加入 QMF 旋转、音调初相调整、limiter 约束、能量地板候选或其它联合诊断。
实验结束后恢复生产表达式；最终 release 从恢复后的源码重建，不能把临时候选留在正式路径。

## 固定 HF 输入的结果

复用 [HF／TNA 调查](ASPX_HF_TNA_INVESTIGATION.md)的 129 个输入：27 次真实调用、48 个
谱形探针及 54 个 TNA 探针。四种候选均通过同一个 `replay_fixed_hf_inputs` 直接调用
生产原语，分别使用原生尺度和既定 `2^23` 生产尺度，比较 1,032 份预平坦化 HF 输出。

原检查器重新验证输入、来源、区间、四个独立参考进程的矩阵及结束状态。新增检查器再
核对各候选的源子带、独立最小二乘增益、运算方向和完整写入范围。每个候选有 1,807 份
非增益／非预平坦化输出文件与起点逐位相同，包含预测系数、chirp、历史及旁路 HF。
本轮没有新启动参考进程；此前有效捕获与失败排除的边界保持不变。

在线性上升／下降谱中，20 个尺度／区间组合的最低功率至少为 `1e4`，其中 16 个使用
生产尺度。该门槛只划分地板可忽略的数学控制，不从真实误差统计中删除弱带。

| 候选 | 输出斜率／输入斜率 | 方向修正后最大绝对斜率 |
| --- | ---: | ---: |
| literal | 1.999993–2.000000 | 不适用 |
| multiply | 约 0 | `1.402e-5 dB/子带` |
| reverse_gain | 约 0 | `1.398e-5 dB/子带` |
| bypass | 1.000000 | 不适用 |

另有 Rust 生产调用判据覆盖三个合法频带布局、线性上升／下降和三次曲线、两个区间。
同一生成器分别消费 P85 增益及其倒数：一支变平，另一支扩大粗谱形；None 保持源样本
逐位搬运。静音与极小输入另行验证。这是候选鉴别判据，不把当前生产标成已通过平坦化修复。

将 P85 强制设为单位增益，或在 HF 生成器漏掉增益应用，判据均失败；同时反转增益表示
和应用方向的数学等价变体通过。新增 Python 检查还拒绝候选重命名、缺文件、改变状态、
错误指数方向、越目标子带写入和非有限输出。

固定真实输入的合计 HF SNR 如下；比较仍停在包络补偿之前：

| 输入／区间 | literal | reverse_gain | bypass |
| --- | ---: | ---: | ---: |
| 强纯音 AU 8 | −7.90 dB | 3.62 dB | 逐位一致 |
| 音乐 AU 100 | 10.69 dB | 6.92 dB | 142.63 dB |
| 音乐 AU 33 | 6.41 dB | 11.64 dB | 143.03 dB |

乘法与差值反向两个修法的 HF 对照约 145.92 dB SNR，最大非零相对差 `1.57e-7`、
最大 2 ULP；全部案例和两种尺度的绝对／相对误差及位差均保留。旁路吻合参考的局部指标
不能代替完整对象 PCM，也不能用来证明规范要求停用预平坦化。

## 最新生产起点上的完整对象 PCM

固定 LFE + 20 个对象身份、`2^-16` 尺度及已有 31 samples 整数延迟，保留完整对齐区间
与尾部，不按能量筛选轨道或拟合增益、相位、延迟。强纯音和音乐各测 limiter=1／0，
另测 128K 音调和 18.1875 kHz 输入；六种流各测既有 boost 选项的开／关。
另外两份仅关闭 preflat 的流使用默认 boost，作为无作用控制。

下表是默认 boost 策略相对当前生产的误差能量改善，正数表示误差降低。
multiply 与 reverse_gain 在表中六位小数精度下相同，完整数值仍分别保存。

| 输入 | reverse_gain 全段 | reverse_gain 12–18 kHz | bypass 全段 | bypass 12–18 kHz |
| --- | ---: | ---: | ---: | ---: |
| 原强纯音，limiter=1 | −0.166346 dB | −0.182908 dB | +0.341789 dB | +0.320579 dB |
| 原强纯音，limiter=0 | +0.383088 dB | +0.389459 dB | +0.110608 dB | +0.112681 dB |
| 独立音乐，limiter=1 | +0.023678 dB | +0.008125 dB | +0.051476 dB | +0.039284 dB |
| 独立音乐，limiter=0 | −0.000458 dB | −0.000488 dB | −0.000086 dB | −0.000061 dB |
| 128K 强音调 | +0.003305 dB | +0.004054 dB | +0.002415 dB | +0.003248 dB |
| 18.1875 kHz 输入 | −1.428677 dB | −3.400446 dB | −0.738059 dB | −1.901732 dB |

最后一份输入的主峰超出固定参考频带，整段评分还包含参考停止带差异；12–18 kHz 的数值
仍完整报告，不因此排除该输入。它不能代表所有实际音乐的结果，也不能支持为本地增加低通。

幅度变化可能大于误差能量变化：原强纯音 limiter=1 的归一化峰值从 **0.468179** 变为
reverse_gain 的 **0.968707** 或旁路的 **0.664505**。这不是全段音量增幅，也没有据此加入
削波或输出归一化。所有输入的峰值、逐路统计及 boost 路径另存；不把波形差分当作听感结论。

控制结果：

- 所有 preflat=0 输出在四个二进制间逐位相同。
- 完全旁路的原流输出，逐位等于当前生产解码对应 preflat=0 流的输出；参考这两对 PCM 也各自相同。
- 每种候选的 limiter=1 流都不受 boost 选项影响，所有对照的 LFE 保持逐位相同。
- 两个数学修法的对象 PCM 有舍入差异，非零差分为 145.24–165.74 dB SNR，未宣称逐位等价。

本轮单项收益不能引用旧联合诊断中同时改相位、游标或其它策略的十几至几十 dB 结果。
