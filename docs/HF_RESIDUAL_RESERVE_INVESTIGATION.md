# 新储备 A-JOC 码流的高频残差与分量归因

日期：2026-11-08；起点 `5786d78`。本轮建立独立参考、扩展测试观察和检查器，生产 DSP、
默认选项、公共 API 与三层 PCM 基线未改。机器记录见
[`hf_residual_reserve_comparison.json`](experiments/hf_residual_reserve_comparison.json)。

## 结论

13 条新 A-JOC 码流全部取得两个独立进程可重复的完整参考对象 PCM。低／中码率素材的
12–18 kHz 差异明显，不能继续用旧音乐中“少数低能量对象”的观察概括它。

四份流、12 个窗口的实际 A-JOC 输入和矩阵消费者进一步分离了差异：低码率窗口在
A-SPX 输出已经出现主要高带残差；1500K 对照的相同频段尚在直接编码的低带中，输入
比较约为 134–139 dB SNR。矩阵目标、实际消费系数和乘法另行核验，未发现新的生产
反例。这不排除已记录的 A-JOC 时序、去相关和最终输出带宽差异。

再对两个低码率窗口的 12 次 A-SPX 调用、28 个包络拆开生成信号与噪声：在**不含交叉项
的分量误差能量之和**中，噪声占约 88.91%／66.53%。固定 QMF 表示之后的噪声差异
主要来自相位约定；生成信号仍有独立残差。本轮没有把这一观察变成新的生产相位补偿。

## 输入、身份和比较边界

输入来自新的宽带 PRBS 与瞬态储备，各有 8／5 个码率配置。只使用这 13 条 A-JOC，
未将另外 15 条 channel-based／IMS 储备计为完整 PCM 覆盖。

首先从 MP4 提取全部编码 AU，要求各 AU payload 串接后的 SHA-256 与原 `mdat` 内容
相同。ffmpeg 默认处理 edit list 时曾少提取一帧，完整帧数门禁拒绝了该结果；随后显式
使用 `-ignore_editlist 1`。所有比较均用同一完整 raw 输入，没有裁掉编码预热或人为加尾帧。

参考固定为既有 DRP 4.3.0.19350 arm64、decoder-only 模式，所有参数设置均检查成功。
关闭 DRC、limiter、DAP，`target_reference_level=0`。每次核对全部输入字节位置、AU
返回码、非空输出、输出尺寸、状态和全文件有限性；完整 PCM 必须匹配无内部观察的基准。

L3 的实际拓扑为 16 路，L4 为 21 路，均含一个 LFE。参考 API 固定分配 21 路，但 L3
只有 16 路实际合成；其余五路在完整文件中严格为零。初始化后逐 AU 的独立 OAMDI
描述符确认为一个静态 LFE 加 15／20 个动态对象，索引与本地显式输出身份相配。
首 AU 的初始化描述符有 10 路，但对应 PCM 全零，单独记录。只去掉未描述的物理填充路，
实际描述但静音的对象仍参与比较；没有按相关性排列对象。

新增 26 次终端观察捕获覆盖全部 2,235 AU，每份流各两次、各五个详细窗口。独立重放
确认 31 样本格式历史、有效通道数和实际返回缓冲，130 个详细窗口逐位复现；其中没有
格式限幅。16 路观察显式区分实际合成路与 API 填充路，未观察的填充地址不计重复性。
因此采用既有、但在这些新输入上再次验证的 raw 比较契约：

```text
local[t] × 2^-16  对比  reference[t + 31]
```

未搜索延迟、相位、轨道排列或增益。统计保留所有实际轨道；完整共同区间另报告逐样本
误差，12–18 kHz 数字来自既有 4096 点 Hann STFT。STFT 不足一窗的尾部不进入频带
统计，仍进入逐样本统计。参考的 ≥18 kHz 输出不作为规范目标。

## A-SPX 出口与实际矩阵输入

宽带使用 AU 170–172，瞬态使用 AU 3–5；同素材的低／高码率对照使用相同 AU。
窗口选择来自固定 31 样本对齐下的能量诊断，不修改整段评分范围。

| 输入 | fullband 路数 | 交叉子带 | 三个窗口的输入 12–18 kHz SNR |
| --- | ---: | ---: | --- |
| 宽带 L4 448K | 7 | 32（12 kHz） | −0.66／−0.62／−0.57 dB |
| 宽带 L4 1500K | 11 | 50（18.75 kHz） | 134.93／134.87／134.63 dB |
| 瞬态 L4 256K | 5 | 30（11.25 kHz） | 5.28／1.24／4.11 dB |
| 瞬态 L4 1500K | 11 | 50（18.75 kHz） | 134.40／135.75／138.56 dB |

使用已冻结的 `R64 / 2^23` 输入接口换算，时隙位移为零。参考实际 dry／wet 消费缓冲、
目标、增量和游标均经独立模型核对；乘法在已经建立的前向误差界内。参考仍采用命中
时隙第一步，本地继续 ADR-0025，不把它混入 A-SPX 入口残差。
本节按名义 12–18 kHz 的 QMF 子带 `32..48` 统计，不能与前表的 PCM STFT 指标混算。

本地四份完整流的矩阵重建与终端 FIR 核对通过。新观察不改变引擎输出。两份瞬态流中，
直接引擎 PCM 与 CLI 的极弱尾部有位差，最大仅 `2.2958874e-41`（CLI 尺度）：显式执行
Scene 的 f32 `×2^-15` 再 `×2^15` 后全部逐位一致。它来自次正规数的单位转换，不能将
直接引擎／CLI 原始字节不等误计为高频残差，也没有放宽数值容差。

## 生成信号、噪声与组装

本地新增 `cfg(test)` 观察：实际生成 HF、信号增益、注噪条件、噪声、音调和组装结果。
各次观察由实际驱动的输出源绑定，并逐位核对组装高带与该源出口。参考同时观察完整
A-SPX 出口和 A-JOC 实际输入指针，逐调用证明二者身份相同；两个独立进程的完整输出
及相关数值重复。12 次调用都没有音调分量。
分量统计覆盖各包络声明的完整生成区间，包括越帧尾部；已从前帧携带的成品不重复生成，
因此该统计也不等于把当前帧的 32 个时隙全部重新分解。

本地 `gain × HF + enabled_noise + sine` 逐位复现组装。参考的信号与噪声由实际消费的
增益行、游标、固定表和独立组装公式重放；最大误差／前向界分别不超过 0.125／0.125。
下一包络可能已经复用 target/estimate 行，故不把那两行冒充上一包络的结束状态。

| 窗口 | 生成信号分量 SNR | 噪声分量 SNR | 噪声占分量误差能量 | 仅改变噪声相位的局部诊断改善 |
| --- | ---: | ---: | ---: | ---: |
| 宽带 L4 448K，AU 171 | 7.13 dB | −4.93 dB | 88.91% | 9.55 dB |
| 瞬态 L4 256K，AU 4 | 5.27 dB | −4.96 dB | 66.53% | 4.79 dB |

占比的分母为 `E_signal + E_noise`，不是完整残差能量。机器记录另外保存交叉项；
`E_total = E_signal + E_noise + 2·<delta_signal, delta_noise>` 的相对闭合余量约
`3.13e-10`／`2.28e-10`，来自组装及表示换算的舍入。

直接在两边各自的噪声表坐标中比较，噪声 SNR 为 45.34／41.78 dB；应用已确认的 QMF
表示换算 R64 后，成为表中的约 −4.9 dB。这个对照隔离了相位约定与幅度残差：噪声表
坐标的吻合不能冒充公共音频坐标的吻合。局部候选只用固定 R64 改变噪声相位，未拟合
参数，但它仍是诊断候选，**不是整段 PCM 改善、可听改善或生产修复依据**。

## 失败捕获与覆盖限制

- 瞬态 L4 1500K 的一次完整基准捕获虽然返回码和尺寸合格，却与另一次有 709 个分量
  不同，集中在末路，峰值异常达到约 91.58。第三次与第一次逐位相同，后续两次终端、
  两次矩阵观察也保持该摘要。异常文件和回执保留并排除；其原因尚未唯一定位。
- 旧观察器固定 21 路合成、9 路 downmix，不适合新的 16 路／5、7、11 路布局。旧失败
  及新布局验证分别记账，不把观察器限制解释为参考拒绝输入。
- 只在两个窗口完成分量归因，不能把 88.91%／66.53% 外推到全部 13 条流或其他节目。
- 未扩大音调、活动 FIC/TIC、companding、短帧、channel-based／IMS PCM 的覆盖；也没有
  新的普遍误差门限或正式符合性结论。

## 复现与下一项

所有媒体、完整 PCM、私有适配器及原始检查点保存在经 UUID 核验的 cache 卷。仓库只存
观察入口、独立检查器、无媒体测试和汇总。以下变量指向同一实验的规范化检查点：

```bash
python3 scripts/compare_object_pcm.py "$PCM_MANIFEST" --output "$NEW_PCM_REPORT"
python3 scripts/check_aspx_component_residual.py "$COMPONENT_MANIFEST" --output "$NEW_COMPONENT_REPORT"
python3 -m unittest scripts/test_check_aspx_component_residual.py scripts/test_check_ajoc_audio_metadata_sync.py
```

下一项应分别裁决**噪声在已选 QMF 基底中的相位约定**与**生成信号的跨子带搬运／
预平坦化／增益贡献**。现有 64 带 QMF、表 D.2 列序和时钟已有独立验证；要改变生产相位，
仍需明确条款依据或不预设参考结果的独立失败性质。新增样本和局部候选不取消这项要求。
