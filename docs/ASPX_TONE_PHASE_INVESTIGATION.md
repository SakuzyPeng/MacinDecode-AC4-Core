## 不经相位表的闭式预测

设 `k` 为绝对子带，`σ_k=(−1)^k`，`ω_k=π(k+0.5)/64`，`s` 为第一项索引，`u` 为
初始化的全局 QMF 时隙。令 `L[t]` 为逐时隙实幅度，静音时仍有连续的时钟，则：

```text
Q_k[t] = L[t] exp(i σ_k π(s+t−u)/2)
exp(i σ_k πt/2) = exp(i 64ω_k t), 对整数 t 成立
```

第二条解释了绝对子带奇偶符号为何必要。代入已独立验证的 P66 FIR 后，时隙相位可以
解析消去。令 `a[j]=QWIN[j](−1)^floor(j/128)`，区间外取零，得到：

```text
H_L[n] = Σ_t L[t] a[n−64t] / 64
y_s[n] = H_L[n] cos(ω_k(n−127.5) + σ_k π(s−u)/2)
```

Python 模型用“每 64 样本放一个实幅度脉冲，再与原型卷积”求 H；Rust 判据使用绝对
时间的抽头和。两者不读 SINE_TABLE 或生产调制表，不拟合幅度、相位或延迟。与一般
复 FIR 的另一次互校覆盖全部 64 子带、四种初相、带静音的包络和非零初始化原点。
QWIN 仍是共享的锁定数据，本轮不重新审计许可窗表。

这直接分开两个概念：

- 初相前移一项使偶数带载波转 `+90°`、奇数带转 `−90°`，H 不变。
- 把整个 PCM 前移 64 个样本，则 H 也变成 `H[n+64]`。

只有 H 在相邻时隙相同的稳态区间，两者才相等；起音、停音或幅度变化处通常不同。
所以不能把初相 1/0 简单消成一份整段整数延迟，也不能只看稳态纯音裁决边界正确性。

## 实际生产连接与覆盖

从有合法来源的 AdjustedGains 进入，测试端固定单子带正弦幅度、清零信号／噪声分量，
随后原样调用 **tonegen → assemble → combine → synthesise**。下一帧继续消费本地
游标、已组装 HF 尾部、合并历史和合成历史，不换回参考状态。

两种合法模板覆盖 A-SPX 范围内的 10–61 子带，其中高带模板交叉点为奇数 19，防止
相对奇偶误用被偶数起点掩盖。这是调整后增益的受控入口，不宣称每个注入位置都会被
所选真实码流的正弦放置规则自然激活。0–9、62–63 的合成原语另有构造模型覆盖。

| 覆盖 | 数量与说明 |
|---|---|
| 完整导出 | **832 条链、5,644,288 个 PCM 样本** |
| 子带与初相 | 52 个子带，索引 0／1；1 的首调用直接使用生产 first_frame |
| 时间网格 | 15 ATS × 倍率 1／2；每帧 15／30 个 QMF 时隙 |
| 跨帧 | 四帧，携带 0 或 3 ATS；非零携带为 FIXVAR→VARVAR→VARVAR→VARFIX |
| 幅度 | 恒定 1；或每区间 `0 → 1 → 0 → 1/4`，验证静音后恢复 |
| 尾部 | 16 个零 QMF 时隙，最终合成状态与新建零状态相同 |
| 普通 Rust 回归 | **512 个组合**，8 个边界／奇偶子带、全部四初相、倍率 1／2、携带 0–3、两种幅度 |

每区间一个包络；不把跨帧四包络冒充同帧多包络覆盖，后者继续由既有游标测试负责。
15／30 时隙不是四项表的整数周期，使误重置、静音停表无法靠每帧绕回原点隐藏。
倍率 1 是工具层合法网格，不改变短帧终端导出的支持范围。

全部结束游标符合绝对时间定义；生成及组装 QMF 数值完全一致。另有 **8,268 个分量**
只在符号零上不同，未将其描述为全 QMF 矩阵逐位一致。恒定包络改变携带分界时，完整
PCM 逐位不变，包含起音及尾部。

| 对照 | 最大绝对误差 | 完整区间 SNR |
|---|---:|---:|
| 832 条生产链与独立闭式 | `1.589e−9` | 146.19–150.98 dB |
| 128 份既有参考原语与固定表示换算后的闭式 | `4.912e−9` | 141.38–143.45 dB |

SNR 相对舍入为 f32 的模型；绝对前向误差使用未舍入的 f64 模型，全部在事先按幅度、
原型绝对和与 `4·eps_f32` 规定的界内。416 个恒定包络案例的载波复幅度最大误差
`1.321e−10`、相位最大误差 `3.561e−9 rad`。不裁掉弱值来获得这些结果。

## 初相改变与整段平移的区别

208 对恒定包络案例的固定稳态区间 `[16×64,32×64)` 满足
`PCM_seed1[n] == PCM_seed0[n+64]`，生产 f32 输出**逐位相同**。
但保留全起停区间后，所有 416 对案例的最大差为 `0.01195–0.01345`，说明把这两种
操作混同会遗漏可观察的边界信号。该数值属于单位音调原语，不是最终对象 PCM 的尺度。

在同一时间比较初相 0 和 1，稳态差分 RMS 约为原信号 RMS 的 `sqrt(2)`，尽管载波幅度
不变。正弦相差四分之一周本就如此：很大的逐样本误差不自动证明频率、包络或解码精度
有错，也不是听感结论。本轮没有完整码流初相 A/B，更没有把该差异记作生产修复收益。

## 参考行为只作单独观察

复用[基底对照](ASPX_BASIS_OPERATOR_INVESTIGATION.md)的 128 份已验证单子带捕获，未新增
参考进程。每份原始构造输入及固定的 3 个前置、29 个音调、16 个尾部时隙都重新核对，
参考文件摘要保留在机器记录中。

既有 `1/R(k)=exp(i(π−ω_k/2))` 加到上述闭式，参考 64 带合成的物理相位便为：

```text
y_ref[n] = H_L[n] cos(ω_k(n−128) + σ_k π(s−u)/2 + π)
```

参考 PCM 使用先前固定的 `2^17` 原语换算，不替换对象 PCM 的 `2^-16`。
该公式预测了完整瞬态，不只解释主峰；但 R 的换算与初相前移一项仍是不同操作。
本次不新增真实偶数音调码流证据，也不把 64 带原语关系外推到所有分析宽度。

## 判据验证和结论

实际临时修改生产代码的四类故障均被新回归捕获：初值改为 0、虚部按相对子带取奇偶、
全静音时冻结游标、读取错误的 HF 携带时隙。初值写成 `5 mod 4`、奇偶符号写成
`1−2·parity` 两种等价变体通过，恢复源码后再次通过。初值故障按 P105 的明确选择判错，
不能拿它声称数学性质自行排除了其余初相。

新增 12 个 Python 测试覆盖独立复 FIR／实包络闭式互校、物理初相与整体平移的反例、
静音时钟、已固定 R，以及遗漏、重复、错误游标、QMF／PCM 破坏、NaN 和截断拒绝。
CI 已纳入。默认／audio-decode 测试、两套 Clippy、格式、层审计与相关 Python 检查通过；
三层 36 条基线复验，未更新任何摘要。所有大文件在已核验身份的 cache 卷，复用 target。

保留生产 QMF 和初相 1，不新增 API、CLI 或兼容开关。这关闭的是当前“必须继续调初相
才能解释误差”的假设，不证明参考的 0 符合或违反其全部内部约定。
下一项更值得独立审查的是[已观察到的 TNA 稳定化差异](ASPX_HF_TNA_INVESTIGATION.md)：
单音、近奇异协方差和清零阈值处是否存在真实数值问题，而不是继续按参考相似度旋转波形。
