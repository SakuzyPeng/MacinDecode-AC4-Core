# MacinDecode AC-4 Core v0.2.0

MacinDecode AC-4 Core 提供 AC-4 码流检视、渲染前场景解码和多格式导出，适合命令行检查、音频处理及 Rust 播放器集成。

## 能力

- 读取 MP4/M4A 与 raw AC-4，提供文本和 JSON 检视，覆盖 presentation、substream、响度、DRC、DE、OAMD、EMDF 与 Core 布局。
- 为已验证的动态 A-JOC 长帧和 A-SPX 子集重建 Core／Full 对象 PCM、LFE 与采样级元数据时间线。
- 导出 PCM WAVE、ADM BWF（BW64／RF64）、DAMF，以及满足固定网格条件的 Apple CAF。PCM 幅度尺度和轨道顺序由 CLI 文档与成功响应说明。
- 提供流式 Scene、纯元数据 Session、容器和检视 Rust API，使用结构化错误及整数时间线。
- 核心模块支持 `no_std`，采用 Rust 2024，MSRV 为 Rust 1.98。

## 下载与运行

发布包覆盖 Linux、macOS、Windows 的 x86_64 与 ARM64。下载平台压缩包及同名 `.sha256` 文件核验，完整校验索引见 `SHA256SUMS`。

预编译 CLI 包含音频解码所需静态表。使用 Rust 库的音频功能时，按仓库文档从锁定的官方规范准备本地表。

```bash
macinac4 inspect input.m4a
macinac4 inspect input.m4a --format json
macinac4 trace input.ac4
macinac4 export-objects-pcm input.m4a -o objects.wav
```

成功命令使用版本化的 JSON 响应，警告和错误通过 JSON Lines 诊断报告。`inspect` 默认输出英文文本。

## 支持范围与验证

Channel-based／IMS 可用于拓扑和元数据检视，其 PCM 重建仍在开发中。音频支持集中于已验证的动态 A-JOC 长帧子集，静态 A-JOC、SIMPLE、短帧、分片／多倍帧率、高采样率扩展及活动 DE、companding、A-SPX FIC／TIC 等路径继续通过结构化诊断报告覆盖边界。

输出的渲染前场景可交给外部扬声器或耳机渲染器。ADM／DAMF 导出的元数据映射限制通过诊断呈现。

验证涵盖 Rust 与 Python 测试、规范与分层审计、本地真实媒体逐位 PCM 基线及多平台一致性检查。向量储备中的非零 DE body 和其他新增语法覆盖按各自的验证层记录。

完整用法、幅度约定和支持矩阵见 [CLI 文档](https://github.com/SakuzyPeng/MacinDecode-AC4-Core/blob/v0.2.0/docs/CLI_USAGE.md)、[输出契约](https://github.com/SakuzyPeng/MacinDecode-AC4-Core/blob/v0.2.0/docs/OUTPUT_CONTRACT.md)和[路线图](https://github.com/SakuzyPeng/MacinDecode-AC4-Core/blob/v0.2.0/docs/ROADMAP.md)。
