# MacinDecode AC-4 Core v0.1.0

首个公开版本，提供 AC-4 码流检视与渲染前对象音频解码。

## 本版支持

- **码流检视**：读取 MP4/M4A 和 raw AC-4，报告拓扑、响度/DRC/DE、OAMD 与 Core 布局，支持文本和 JSON。可独立观察元数据，无需重建 PCM。
- **音频解码**：覆盖已验证的动态 A-JOC 长帧、A-SPX 子集，输出 Core/Full 对象 PCM、LFE 与 OAMD 时间线。
- **场景导出**：PCM WAVE、ADM BWF、DAMF；Apple CAF 支持满足固定网格及直接输出条件的 5.1、5.1.2、5.1.4、7.1.4 场景。
- **集成与平台**：提供 Rust Scene/metadata API，以及 Linux、macOS、Windows 的 x86_64/ARM64 预编译命令行工具。

## 当前限制

- Channel-based/IMS 支持拓扑与元数据检视，尚不提供 PCM 重建；direct-object 尚无公共场景输出和真实媒体验证。
- PCM 解码暂不支持静态 A-JOC、SIMPLE、短帧、分片/多倍帧率、高采样率扩展，以及活动 DE、companding、A-SPX FIC/TIC 等路径。
- 输出供外部渲染器使用，不执行最终扬声器/耳机渲染、响度管理或编码；ADM/DAMF 无法等价保留的元数据会通过诊断报告。

详细用法与支持矩阵见 [CLI 文档](https://github.com/SakuzyPeng/MacinDecode-AC4-Core/blob/v0.1.0/docs/CLI_USAGE.md)和[路线图](https://github.com/SakuzyPeng/MacinDecode-AC4-Core/blob/v0.1.0/docs/ROADMAP.md#音频重建与-corefull-场景输出支持矩阵)。
