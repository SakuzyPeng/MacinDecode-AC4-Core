# ADR-0022：修正 A-SPX 预平坦化增益的方向

日期：2026-10-17。状态：已采用；跨条款的本地判读，不声明存在官方勘误。

## 问题与独立依据

`TS103190-1:v1.4.1:5.7.6.4.1.1` 和 `5.7.6.4.1.4` 的 P89 都描述在 patch 时除以
预平坦化增益；`5.7.6.4.1.2` 的 P85 却计算 `10^((mean_energy − slope)/20)`。
本地此前忠实执行这一组合。在零预测项、高能量且可由三阶多项式准确描述的谱上，它
会把粗谱斜率扩大近两倍，与该工具的平坦化目的冲突。

设低带平均功率为 P，`e=10*log10(P+1)`，其三阶最小二乘投影为 f，平均值为 m。
高能量时，旧组合的输出 dB 包络近似 `e+f−m`；移除粗谱形则应得到 `e−f+m`。
非多项式谱保留投影残差；低能量处保留地板，不能要求输出完全平坦或总能量不变。

[方向调查](../ASPX_PREFLATTEN_DIRECTION_INVESTIGATION.md)已经区分修正方向与参考旁路。
本次采用的依据是上述独立性质和生产反例，DRP 差分不作为正确性门禁，也没有采用旁路。

## 决策与范围

只反转 `preflatten::pre_flatten` 中 P85 指数的差值：

```text
gain_vec[sb] = 10^((fitted_envelope[sb] − mean_energy)/20)
```

P89 保持对完整预测残差除以源子带增益。选择这一最小修改，是为保留正文与 P89 一致的
应用方式；数学上也可改 P89 为乘法，但两种实现存在舍入差。本决策不宣称唯一定位了
原规范的笔误位置。

拟合器、`+1` 地板、统计区间、计算精度、patch 映射和原始低带历史不变。TNA、QMF、
音调初相、limiter、注噪预算和已有 boost 默认值不变。不新增公共 API、CLI 参数、输出
字段或兼容开关；码流 preflat=1 的真实音频出口采用修正，preflat=0 不受影响。

## 从旧式失败到生产回归

原调查判据只要求“两个方向中有一个变平”，不能约束生产选择。现在直接串联生产
`pre_flatten → hf_generate`，不替换生产增益、不在测试端取倒数帮助它通过。
合法 patch、零预测项、80 dB 基准的线性谱在旧式首先失败：`sbx=10`、区间 `[0,32)`、
目标子带 10 相对平坦电平偏离 **17.77777774 dB**。同一判据在修复后通过。

回归包括三个现有合法频带布局、线性上升／下降与三次曲线、零和非零起点，采用已有的
`2e-4 dB` 容差。平坦谱、全零／近零、单带静音、峰与凹口、不同跨度也单独覆盖。

非多项式与地板检查使用对称网格上的四条显式正交多项式投影，与生产的 Cholesky
正规方程不同；另验残差正交、拟合四阶差分为零及非零残差，防止独立模型本身退化。
期望输出从输入功率及该独立投影推得，不读取生产 gain 作为期望值。固定非零复数预测
系数和 chirp 后，整段预测残差仍接受同一正实数缩放，实虚两部及源子带映射共同验证。

四点精确拟合的旧同形指数测试改为两项性质：`(P+1)/gain²` 处处相等、除数几何平均为 1。
NaN、正负无穷在实／虚两部的拒绝均验证输出事务性。

缺陷注入恢复旧符号、漏掉增益应用、读取错误源子带、每帧重置噪声游标，全部被对应
判据捕获；等价的差值改写通过。这些检查证明实现符合所采用的独立判读，不宣称 AC-4
全部路径已经符合规范。

## 连续本地链

新增生产流水线检查覆盖 24 组配置、96 帧：两档时隙倍率 × 三种 limiter 模式 × 插值
开／关 × 有／无音调，每组四帧。包含 FIXVAR 越帧后接 VARFIX、当前 onset、上一间隔
末尾指针、音调停用以及正常区间。倍率 1 使用内部 A-SPX 原语，不扩大公开短帧支持。

各段实际消费上一段本地产物，连续保留本地状态，不从 DRP 检查点重置中间历史：

- 对实际 HF 按时频区域独立平均，核对包络估计；用该估计复算已有增益原语，验证接线。
- 按独立的包络位置和注噪预算逐分量核对组装；HF 尾部与下一帧继承头逐位相同。
- 用连续 QMF 输入历史直接验证合并结果，并记录 HF、噪声、Y、输出能量、估计和增益范围及结束游标。
- preflat 开／关的原始分析、低带、TNA、chirp、包络／正弦控制、输出延迟和生成器游标一致；已处理 HF 成品允许改变。
- 固定同一组 A-SPX 区间，中途重建工作区后继续运行，所有边界数据和结束状态保持一致。

这里没有要求改变实际统计区间后仍产生相同 PCM，也没有要求采用 DRP 的内部算法。

## 重放记录与历史兼容

新 HF 重放写入测试专用 `replay_metadata.json`，明确标记
`preflatten_gain_convention=slope_minus_mean`。缺少标记的旧记录始终按
`mean_minus_slope` 解释；无效标记或与增益不符的声明直接失败。

129 个固定 HF 输入的全部 **2,323 个既有输出文件**逐位复现先前 `reverse_gain` 候选，
新增约定标记另行检查。旧记录按旧式重读，全部历史指标保持不变，没有重命名或覆盖旧结果。
原参考检查点只用于独立观察，本轮没有新增参考捕获。

## 完整 PCM 影响与回归

重新导出 8 种完整流、14 种选项组合，全部逐位复现冻结候选。相对修复前，默认 boost
策略的参考误差能量变化如下；正数表示与 DRP 的差分降低，不作为修复正确性的得分。

| 输入 | 全区间误差改善 | 12–18 kHz 误差改善 |
| --- | ---: | ---: |
| 原强纯音，limiter=1 | −0.166346 dB | −0.182908 dB |
| 原强纯音，limiter=0 | +0.383088 dB | +0.389459 dB |
| 独立音乐，limiter=1 | +0.023678 dB | +0.008125 dB |
| 独立音乐，limiter=0 | −0.000458 dB | −0.000488 dB |
| 128K 强音调 | +0.003305 dB | +0.004054 dB |
| 18.1875 kHz 输入 | −1.428677 dB | −3.400446 dB |

固定全 21 路身份、`2^-16` 尺度、已有 31 samples 整数延迟，保留完整对齐区间与尾部。
计分未应用增益、相位或延迟拟合；18.1875 kHz 主峰超出固定参考带宽，相关限制沿用调查记录。
原强纯音 limiter=1 的归一化峰值从 0.468179 变为 0.968707，完整峰值另列机器记录。
这不是全段音量变化或可听改善的结论，没有加入削波、低通或归一化。

所有 preflat=0 控制与 LFE 逐位保持；limiter=1 时 boost 开关仍逐位无作用。
默认／音频测试通过 **516／1,318** 项，相关 Python **155** 项，两套 Clippy、格式和
层依赖审计通过。Core 12 条基线保持；A-SPX／对象层各 12 条仅 PCM 摘要有意更新，
形状、身份和其它字段不变，更新后 36 条复验通过。

源与二进制摘要、反例、缺陷注入、连续链覆盖、重放、完整误差和逐条基线变更见
