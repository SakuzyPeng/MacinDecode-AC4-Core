# ADR-0008：QMF 合成的成对调制

- 状态：Accepted
- 日期：2026-08-25
- 关系：服从 [ADR-0002](0002-numeric-format-for-reconstruction.md) 的逐位标量约束；使用 [ADR-0003](0003-trigonometric-tables-for-the-transform.md) 的冻结 QMF 相位表

## 背景

`TS103190-1:v1.4.1:Pseudocode 66` 的合成调制对每个 QMF 时隙执行 `128 × 64` 项直接求和：

```text
y[n] = (1/64) Σ_sb Re{X[sb] · exp(j·2π·(2sb+1)·(2n−255)/512)}
```

Apple M4 Pro 的符号级采样显示，这一调制占整个 `synthesise` 的 Core `96.57%`、Full
`96.48%`，分别占完整解码约 `41.36%` 和 `50.83%`。多相窗尾只有约 `1%` 的全程收益空间，
因此继续优化窗尾没有意义。

实现仍须满足 `no_std`、稳态零分配、禁止 FMA/fast-math、portable release，以及现有 Core、
A-SPX 和 A-JOC 对象 PCM 逐位门禁。数学等价但改变浮点加法结合顺序的变换不能直接替换标量
基线。

## 决策

1. **合成输出按 `n` 与 `127−n` 成对计算。** 令 `q = 2sb+1`、`a = q(2n+1)`，其中
   `n = 0…63`。两行在 512 点单位圆上的指数分别为：

   ```text
   q(2n−255)       = a−256q ≡ a−256
   q(2(127−n)−255) = −a                         (mod 512)
   ```

   `q` 恒为奇数，所以第一行相位恰为 `−exp(ja)`，第二行恰为 `conj(exp(ja))`。
2. **每个子带只计算一次 `real = re·cos` 和 `imaginary = im·sin`。** 两个输出项分别为
   `imaginary−real` 与 `real+imaginary`。这把每时隙的乘法和相位加载从 8,192 组减为
   4,096 组；两个输出各自仍严格按 `sb = 0…63` 累加，累加次数与顺序不变。
3. **继续使用同一张冻结的 f32 QMF 单位圆表、f64 乘法/累加和最终 f32 收窄。** 不使用 FMA、
   SIMD、额外表、额外工作区或堆分配。
4. **测试中保留逐行定义式 oracle。** 全部 4,096 个“输出对 × 子带”相位先核对逐位负共轭
   关系；19 个确定性非零时隙和 10 个有限边界时隙（含 `±0`、subnormal、最小 normal 与
   `±f32::MAX`）逐项比较 128 个调制输出。拆分前的完整 `Pseudocode 66` 字面实现继续比较
   PCM 和 1,280 项跨帧状态。
5. **保留手动 release 微基准。** 五轮交替执行逐行 oracle 与成对实现，使用中位数判断局部
   内核收益；它不进入 CI 性能门禁。

## 验证证据

### 正确性

- 成对实现对上述确定性与有限边界输入逐位等于定义式；完整合成状态与 PCM 逐位等于拆分前
  字面实现。
- `scripts/decode_check.py` 的 Core、A-SPX 和 A-JOC 对象 PCM 真实向量全部保持既有摘要；两条
  尚未实现的 channel-based IMS 向量仍按既有规则跳过。
- 普通构建没有新增工作区；`stats_alloc 0.1.10` 对 24/24“媒体 × 模式”组合继续得到零
  allocation、reallocation、deallocation 和 bytes。

### 性能

M4 Pro、macOS 27.0、Rust 1.96.0，普通 portable release。局部调制微基准五轮中位数从
`4,012.994 ns/slot` 降至 `2,360.331 ns/slot`，即 `1.700×`。

完整 A/B 冻结二进制 SHA-256：

- before：`5f3b6c38b9493f833c45d91b452a9db2d0541afe63e5cb2eb0936a1c32c4cc5b`
- after：`58218f7b80c28f0800aec88dfa826f88f6402f3209d5accf8903605390b34066`

12 条真实媒体的 Core/Full 共 24 项，各执行五轮交替 A/B；每项先完整预热，再固定测 5 个完整
pass。按每项五轮中位数，24/24 总时长改善、24/24 p99 改善：

| 模式 | 汇总总时长改善 | 单项总时长改善范围 | p99 改善范围 |
| --- | ---: | ---: | ---: |
| Core | 20.94% | 20.61%–21.25% | 18.85%–21.77% |
| Full | 24.35% | 23.31%–25.84% | 22.29%–27.58% |

标准 1500K 的独立五轮 A/B 中，Core 五个 pass 中位总时长由 `2.776 s` 降至 `2.201 s`
（20.73%），Full 由 `6.105 s` 降至 `4.656 s`（23.73%）。

全套 after 首轮的 Full DME L4 768K 3DoF 在 pass 3 / AU 67 捕获一次 `60.310 ms` wall-clock
延迟，超过 `42.667 ms` 预算；其余四轮未 miss。随后对同一案例再做五轮 after、3,575 次 AU
调用，0 miss，最大 `7.719 ms`。原始异常不删除，也不据此宣称“从未 miss”；结合该案例总时长
改善 24.59%、p99 改善 24.90%、定向复测未复现，将其记录为一次非稳定 wall-clock 离群值，
而非成对内核的可复现回归。

完整汇总见 [M4 Pro QMF 成对调制 A/B](../experiments/m4_pro_qmf_paired_ab.json)，原始逐轮 JSON
只保留在 `target/perf/`。

## 被否决方案

### 128 点 FFT 前/后旋转

原定义可精确写成“64 个输入预旋转并补零 + 128 点正号 DFT + 输出后旋转”。复用现有 Stockham
内核的单轮探索微基准达到 `3.339×`，但蝶形改变加法结合顺序：19 个非零时隙的 2,432 个 f32
调制输出中有 1,435 个（59.00%）位模式不同，最大绝对差 `1.49×10⁻⁸`、相对 RMS
`6.00×10⁻⁸`。误差虽小，仍违反既定逐位门禁，因此否决。

### 完整 `128 × 64` 相位矩阵

按输出行连续存储 64 KiB 相位矩阵可保持逐位输出，单轮探索微基准为 `1.181×`。它只省去已被
编译器强度削弱为位掩码和递增步长的索引计算，收益远低于成对方案，还增加只读数据与缓存压力，
因此否决。

### SIMD

本决策只建立 portable 标量优化，不引入目标特定 intrinsic。未来 SIMD 内核仍须保留本实现作为
独立标量 oracle，并单独证明跨平台舍入与逐位 PCM。
