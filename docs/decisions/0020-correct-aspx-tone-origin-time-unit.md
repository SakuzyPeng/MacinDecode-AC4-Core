# ADR-0020：修正 A-SPX 音调游标起点的时间单位

日期：2026-10-16。状态：已采用。

## 背景

`TS103190-1:v1.4.1:5.7.6.4.4` 的 P104 以 QMF 时隙循环，P105 却减去 ATS 单位的
`atsg_sig[0]`。原实现保留该字面式；倍率为 2、左边界非零时，会额外推进
`atsg_sig[0] × (num_ts_in_ats − 1)` 个音调表项，并将该偏移携带到后续区间。

[独立调查](../ASPX_TONE_CURSOR_INVESTIGATION.md)将三项问题分开：本地 last 与参考 next 的
状态表示、区间起点的时间单位，以及初始化索引。分段不变性、1,376 个同输入案例及真实
非零音调检查点支持起点换算；初相 0 则是另一项参考行为，不能由连续性条件直接推出。

## 决策

在 `tonegen::generate` 中采用：

```text
origin_qmf = atsg_sig[0] × num_ts_in_ats
base = first_frame ? 1 : previous + 1
sine_index = (base + ts − origin_qmf) mod 4
```

作为默认算法修复应用，不新增 API、CLI 参数或兼容开关。初相仍取 P105 明写的 1；
`ToneCursor` 仍保存最后一项，四项表、绝对子带奇偶符号、`first_frame` 的初始化语义、
包络选择、输出范围、来源验证及错误事务性保持不变。噪声起点已经按 ADR-0019 修正，本轮
不再改变；QMF、预平坦化、增益与 limiter 策略也保持原样。

这是有独立数学和参考边界证据的本地规范判读，偏离 P105 起点的字面，不声明存在官方勘误。
同一初态下，倍率为 1 或左边界为零的当前区间与旧式相同；修正过历史偏移后，后续零起点
区间也可能改变。静音期间游标同样继续推进。

## 回归与重放

新增连续时间轴的分界不变性回归，固定电平并覆盖倍率 1／2、四种分界、奇偶起始子带和
初始化／续跑，比较完整三帧波形与结束游标。旧实现首先在倍率 2、分界 1 的续跑案例失败，
修复后通过。旧的“未乘倍率”判据改为同时检查初相仍为 1、实际生成 28 项后游标为 0。

测试重放的 `qmf_origin` 现在原样传递游标和 `first_frame`，直接调用生产；`literal` 仅在
测试端添加确定偏移重现旧式。`literal_initial_zero`、`qmf_origin_initial_zero` 继续只作
初始化诊断。比较器兼容旧记录的模式名，并明确标注其生产起点，避免混淆历史与当前结果。

四种模式的 1,376 份输出都逐位复现对应的前轮矩阵。当前生产与参考仍有 40 个结束游标差异：
36 个明确初始化案例，以及其中 4 个后续携带案例；同初态的非首帧起点差异已消除。剩余初相
差异、符号零差异均继续报告，不称为生产已与参考完全吻合。

默认／audio-decode 测试分别通过 516／1,299 项，相关 Python 53 项、两套 Clippy、格式与
层审计通过。三层基线中 Core 12 条逐位不变，A-SPX／objects 各 7 条摘要有意更新、5 条不变；
所有采样率、声道数、帧数、轨道身份和其它字段保持不变，更新后 36 条全部通过。

## 单项端到端影响

比较只改变音调起点，固定既有轨道身份、`2^-16` 幅度尺度及 31 samples 整数延迟，覆盖全部
21 路与完整对齐区间（包含尾段）。下表使用默认 boost 策略，正数表示相对 DRP 的误差能量增加：

| 输入 | 全区间误差增加 | 12–18 kHz 误差增加 | 峰值变化 |
| --- | ---: | ---: | ---: |
| 原强纯音，limiter=1 | 0.934473 dB | 0.862159 dB | +1.363336 dB |
| 原强纯音，limiter=0 | 0.786382 dB | 0.720798 dB | +0.058926 dB |
| 独立音乐，limiter=1 | 0.000184 dB | 0.000092 dB | 0 dB |
| 独立音乐，limiter=0 | 0.000151 dB | 0.000078 dB | 0 dB |
| 128K 强音调 | 2.245231 dB | 2.241945 dB | +0.966974 dB |
| 18.1875 kHz 输入 | 0.109863 dB | 0.000965 dB | +0.016055 dB |

18.1875 kHz 主峰在固定 12–18 kHz 统计范围之外，不以该频带结果评价主峰。各输入也单独测了
显式 boost；码流 limiter=1 时开关仍逐位无影响，所有修复前后 LFE 都逐位不变。原强纯音在
limiter=0 且显式 boost 时，按固定比较尺度计的峰值达到 **1.001554**；完整峰值与误差数据
见 [`aspx_tone_origin_fix.json`](../experiments/aspx_tone_origin_fix.json)。

本次收益是消除区间分界造成的时钟跳号。测得的整体参考误差没有改善，尤其强音调仍受初相与
QMF 表示影响；这些数值是波形差分，不能当作听感结论。初相、QMF 基底和预平坦化继续各自
裁决，不借此单项修复一并改变生产策略。
