# ADR-0024：无交织完整 A-SPX 的高带只选择 SEC

日期：2026-10-20。状态：已采用。

## 问题与独立依据

此前完整 A-SPX 无论是否使用交织，都把延迟的全带分析输入加到已组装的 Y 上。
QMF 过渡带使原输入在交叉子带之上仍可非零，这项泄漏因此成为未选择的额外高带分量。
原先“时间交织替换会丢掉 Y，所以默认相加”的论证漏掉了低带直通、高带保留 Y 的选择。

`TS103190-1:v1.4.1:5.7.6.1` 把输出描述为低带、SEC 和交织 WCC 的组合；
`5.7.6.5.1`–`5.7.6.5.3` 将 WCC 的相加／替换置于相应信令条件下。按此条件读法，
无交织完整 A-SPX 不应在 SEC 之外再加入未选择的高带 WCC。
规范没有单列该情形的完整分段公式，本决策明确作为本地判读，不宣称官方勘误。

[合并调查](../ASPX_MERGE_INVESTIGATION.md)的独立反例实际调用完整生产 API：合法频带
和包络配置，连续三帧 4,078.125 Hz 纯音，交叉子带 11。低带和 SEC 都非零，但旧输出的
高带 `Q_out − Y` 最大实／虚分量为 168.20998。该属性来自分量条件，不由参考分数选定。
同输入参考边界支持这一读法，但不是唯一正确性依据。

## 决策与最小实现

仅对完整、活动且无交织的 A-SPX 采用：

```text
sb < sbx:   Q_out[sb,ts] = delayed(Q_in)[sb,ts]
sb >= sbx:  Q_out[sb,ts] = Y[sb,ts]
```

`sbx` 取本调用已经验证的频带表，选择覆盖到子带 63；Y 在生成范围外为零。
原始分析矩阵、低带与 TNA 历史、已组装 Y 及其携带尾部都不被该选择改写。

新增私有 `pipeline::combine_hf_to_qmf`：先调用既有相加尾段推进完整原始分析历史，
再只替换输出高带。低带保留既有浮点结果；Y 的低带仍由原准备／组装契约保证为零。
不提前裁掉输入或延迟历史，因而后续交叉子带升降、延迟档 3／6 切换仍能读取原始样本。

单声道、独立双声道和平衡双声道的完整入口均接入此私有尾段。通用 `interleave::combine`、
三个未组装 HF 的诊断入口、LFE 延迟路径与 SIMPLE 路径维持原行为。
活动 FIC/TIC 仍被 Full 支持检查拒绝；本决策不增加交织支持。

没有新增公共 API、CLI 参数、兼容开关、状态字段或逐帧分配；QMF 相位、TNA、
预平坦化、limiter、噪声／音调及其游标策略均不调整。

## 验证与历史保留

反例先升级为普通回归并在旧生产失败，修复后高带额外分量严格为零。另验证：

- 交叉子带升降、延迟档切换时原始历史保留；分析输入、Y 和帧外输出不变。
- 独立双声道采用不同交叉子带，各自与标量入口逐位一致；平衡双声道的分段输出由独立
  QMF／合成预期核对。既有 FIXVAR→VARFIX、两个时隙倍率和连续相位变换测试通过。
- 新生产尾段逐位复现此前 2,311 个冻结选择候选，包括全部 QMF 和 14,198,784 个 PCM
  样本。旧调查的相加／选择结果、输入及摘要保持，不把旧记录改名成新生产。
- 恢复相加、漏掉交叉子带、丢最后低带、预先裁剪原始历史、漏虚部、漏独立第二声道或
  平衡第一声道，七类故障均被捕获；等价索引转换与恢复后的实现通过。

普通默认／audio-decode／spec-tables 测试、三套 Clippy、格式、层／数学检查和
默认／audio-decode 的 thumbv7em `no_std` 编译通过。三组合成跨平台夹具的 Core 摘要、
输入和形状不变，仅更新六个 A-SPX／对象摘要；ARM64 与 x86_64 的冻结位检查均通过。

## 实际影响与基线

8 种完整流、14 个选项组合按既定身份、`2^-16` 尺度和 31 样本整数延迟比较。
全部输出有限，轨道身份、长度不变，LFE 逐位保持，limiter=1 时 boost 选项仍无作用。

独立音乐 limiter=1 的全段参考误差能量下降约 **0.01085 dB**，12–18 kHz 下降约
**0.00789 dB**；limiter=0 及 preflat=0 音乐的全段改善约 0.0105–0.0109 dB。
纯音变化很小，部分指标略增。内部泄漏的独立贡献不等于完整对象输出的修复收益，
也不据这些分数追加相位或增益调整。

Core 12 条基线逐位不变；A-SPX／对象各 12 条仅更新预期 PCM 摘要，形状和身份不变，
更新后全部 36 条复验通过。详细对照、峰值、故障注入和摘要见
[`aspx_merge_fix.json`](../experiments/aspx_merge_fix.json)。
