# ADR-0027：保留 A-SPX 微小功率开方后的可表示幅度

日期：2026-11-08。状态：已采用。

## 决策

P94 的分配公式保持不变。当 `S/(1+Q)` 或噪声功率的 f32 中间值进入次正规范围
或下溢为零时，以 f64 重算受影响的幅度，只在开方后收窄。常规 f32 路径及其舍入
保持不变；只有噪声功率失精度时，正弦幅度仍沿用原路径。

这是数值实现修复，不重新解释预平坦化、limiter、注噪条件或相位。没有放宽反量化
接受范围，也没有承诺任意极端包络历史都能完成 Full 解码。

## 独立反例

依据 `TS103190-1:v1.4.1:5.7.6.4.2.1` 的 P94：

```text
N = sqrt(S × Q / (1 + Q))
T = sqrt(S / (1 + Q))    // sine_index 为真
```

`S=2^-126, Q=2^-24` 都是正规 f32。旧代码先计算噪声功率并收窄到零，随后开方
得到零；数学结果的幅度可表示，正确的最近偶数舍入是 `2^-75`，位型 `0x1a000000`。
`S=2^-126, Q=64` 则使分配因子成为次正规数，旧噪声位型 `0x1ffe060c` 与独立
100 位 Decimal 锚点 `0x1ffe05ec` 相差 32 ULP；正确正弦位型为 `0x1e7e05ec`。

两个反例通过公开的包络差分解码与反量化 API 构造：从合法初值按有界的 ±1 时间差分
推进，每步都核对反量化结果为正规数。它们没有直接填充 `ScaleFactors` 私有数据，
也不是新编码出的真实码流向量。测试先在旧实现上得到两项失败，再验证修复通过。

## 选择理由与验证边界

两个有限正规 f32 的这些功率中间量在 f64 中可表示；先开方再收窄保留了幅度信息。
对全部输入改用 f64 也能解决反例，但会扩大常规舍入变化，本次只处理已经失精度的
中间值。保留零输出或钳到最小功率都会改变上述已明确可表示的数学结果。

五项 Rust 回归覆盖独立锚点、常规舍入、1,778 组功率预算、连续边界和零值控制。
36 项已冻结的 core/A-SPX/objects PCM 基线、21 条调查流的完整对象输出均逐位保持。
57 次真实 A-SPX 调用的 2,716 个子带包络没有触发此回退，不能把本修复说成主高频
残差的解决方案。`no_std` 目标也已通过。
