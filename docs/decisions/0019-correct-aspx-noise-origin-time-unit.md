# ADR-0019：修正 A-SPX 噪声游标起点的时间单位

日期：2026-10-16。状态：已采用。

## 背景

`TS103190-1:v1.4.1:5.7.6.4.3` 的 P102 以 QMF 时隙循环，P103 却减去 ATS 单位的
`atsg_sig[0]`。原实现保留该字面式；倍率为 2、左边界非零时，会额外消耗
`num_sb_aspx × atsg_sig[0]` 个噪声表项，错误游标随后继续跨帧携带。

[独立调查](../ASPX_NOISE_CURSOR_INVESTIGATION.md)提供两类证据：同一全局时间轴改变区间分界
应保持噪声序列不变；固定输入、增益和初始状态的参考原语对照支持先换算 QMF 起点。464 个
构造案例覆盖绕表、静音、onset 抑制、重置、多包络及连续区间；真实音乐 AU 33 的非零
左边界也复现了额外 60 项跳号。该依据不依赖末端 PCM 误差最小化。

## 决策

在 `noisegen::generate` 中采用：

```text
origin_qmf = atsg_sig[0] × num_ts_in_ats
noise_index = (previous + num_sb_aspx × (ts − origin_qmf) + sb + 1) mod 512
```

作为默认算法修复应用，不增加公共配置或 CLI 参数。表 D.2 的实虚列序、初始下标 1、
`master_reset`、输出范围、来源验证和错误事务性保持不变；音调发生器、QMF 基底、
预平坦化及 limiter 策略也不属于本次改动。它是有数学及外部边界证据的本地规范判读，
不声明 ETSI 已发布相应勘误。

相同初始游标下，倍率为 1 或左边界为零时，本区间输出与旧式相同。发生过额外跳号的
历史被修正后，后续左边界为零的区间也可能改变，这是跨帧状态修复的正常结果。

测试重放的 `qmf_origin` 模式现在直接调用生产路径；`literal` 仅在测试中通过确定的输入
游标偏移重现历史读法，保留旧记录可比性。生产验证不再依靠先补偿输入游标来获得一致。

## 验证与影响

新增连续时间轴分界不变性回归，在旧实现上因倍率 2、分界 1 失败，修复后通过。
原来锁定“未换算起点”的判据改为检查首项和实际消耗的时隙数。修复后的生产生成器复跑
464 个同输入案例，全部结束游标及噪声数值与参考对齐，且与之前已验证的诊断输出逐位相同。
416 个可辨识案例的 408,000 个实／虚分量严格逐位匹配参考；静音中的符号零差异单列。

三层基线中，Core 的 12 条保持逐位不变；A-SPX 和对象阶段各 12 条 PCM 摘要有意更新，
采样率、声道数、帧数、轨道身份和其它基线字段均不变。更新后 36 条全部通过。
默认／audio-decode 测试分别通过 516／1,296 项，相关 Python 43 项、两套 Clippy、
格式与层审计通过。

**端到端误差没有随局部修复普遍下降。** 固定原有尺度、延迟和全部轨道，未加入其它 DSP
变体，默认补偿策略下的结果如下；正数表示相对 DRP 的误差能量增加：

| 输入 | 全区间误差增加 | 12–18 kHz 误差增加 |
| --- | ---: | ---: |
| 纯音，limiter=1 | 0.000384 dB | 0.003781 dB |
| 纯音，limiter=0 | 0.019224 dB | 0.015828 dB |
| 独立音乐，limiter=1 | 2.636155 dB | 2.892613 dB |
| 独立音乐，limiter=0 | 2.706365 dB | 2.932613 dB |

另单独验证了显式 boost 策略，完整 before/after 指标见
[`aspx_noise_origin_fix.json`](../experiments/aspx_noise_origin_fix.json)。这些数字是波形差分，
不是响度变化或听感结论。噪声时钟的独立校验成立，全链路的 QMF 表示、音调初相和其它
高频残差仍需逐项定位；本次不能标作整体参考精度提升。
