# ADR-0017：按协方差正规方程修正 A-SPX 预测器交叉项符号

- 状态：Accepted；跨条款解释，尚无 ETSI 勘误或官方 PCM 向量确认
- 日期：2026-10-01

## 问题

`TS103190-1:v1.4.1:5.7.6.4.1.3` 的 `Pseudocode 87` 写作：

```text
alpha0 = (-cov[0][1] + alpha1 * conj(cov[1][2])) / cov[1][1]
```

本实现此前逐字采用加号，但它与同节 `Pseudocode 86` 的协方差定义，以及
`5.7.6.4.1.4` / `Pseudocode 89` 的加法滤波器不相容。令三个抽头分别为当前、前 2、
前 4 个 QMF 时隙的信号，`cij = Σ xi·conj(xj)`，则预测残差及第一条正规方程为：

```text
r = x0 + alpha0*x1 + alpha1*x2
Σ r*conj(x1) = c01 + alpha0*c11 + alpha1*conj(c12) = 0
```

因此交叉项应取减号。原文 `alpha1` 的公式也与这一选择相容；不能把冲突归为系数命名或
复数相位约定。保留原行列式的 `epsilon = 2^-20` 后，闭式解等价于只对第二抽头添加
`lambda = |c12|²/c11 × epsilon/(1+epsilon)` 的 ridge 项，第一条正交条件保持不变。

## 决策

1. `tna::solve` 改为 `alpha0 = (-c01 - alpha1*conj(c12))/c11`。这是对相互冲突条款的
   数学裁决，明确偏离 P87 的加号字面，不标成已公布的规范勘误。
2. 保留原协方差时序、正则化、复数共轭、模达到 4 时双系数置零，以及 f64 计算/f32 存储。
3. 不同时应用 QMF 相位、噪声或音调游标、预平坦化旁路、limiter 常量等实验变体。
4. A-SPX 及对象 PCM 基线按本次单项数值变动更新；Core 基线保持原摘要。采样率、帧数、
   声道身份、公开 PCM 尺度及输出格式保持原契约。

## 独立证据与回归判据

[`check_aspx_math.py`](../../scripts/check_aspx_math.py)用构造复数时序建立增广最小二乘，
不使用闭式解作为 oracle；减号结果与独立解一致，加号不满足第一条正规方程。
[调查记录](../ASPX_PHASE_INVESTIGATION.md)另保留真实音乐差分及未触发相关分支的纯音对照。
参考差分作为支持证据，数学闭合是本决策的主要依据。

Rust 判据直接约束被测实现：

- 将求出的系数施加到复数时序，检查预测残差与第一延迟抽头正交，覆盖符号和共轭。
- 用 `1 + 0.5*i^m` 双音序列，经真实系数生成和 HF 生成器验证未阻尼预测残差足够小。
  单频旧用例的 `alpha1 = 0` 会隐藏此错误，不能替代双音判据。

两个判据在旧加号实现上均失败；旧双音残差能量约为 36.21，大于输入的 10。原来复制 P87
加号算期望值的测试被正交条件替代，不通过同步修改实现和同形期望值来“修复测试”。

## 影响与限制

修复会改变实际启用 TNA 的 A-SPX 高频及后续对象 PCM；单项外部误差变化必须按本次生产
版本实测，不能引用先前联合诊断的 18–30 dB 作为本修复收益。新的逐位基线及生产比较记录见
[`aspx_tna_sign_fix.json`](../experiments/aspx_tna_sign_fix.json)。

预平坦化和 QMF/游标问题仍未裁决。本修复不声明完整 AC-4 conformance，不扩大 IMS、短帧
或 direct-object 支持范围；若取得官方勘误或向量，应重新核对本决策与所有受影响基线。
