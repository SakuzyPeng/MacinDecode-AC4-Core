# ADR-0018 局部能量补偿对照

日期为 2026-10-04。研究范围为本地对照实验。

## 问题与依据

`TS103190-1:v1.4.1:4.3.10.1.7` 表 122 定义 limiter 开关，
`5.7.6.4.2.2` 的 P95–101 对关闭标志的作用范围存在待复核的本地判读。
公开实现的关闭路径采用 P95/P94 初始结果，开启路径执行 P96–101。

[参考检查点记录](../experiments/aspx_reference_checkpoints.json)观察到，
所测参考路径在 limiter 关闭时仍存在补偿和有限增益约束。研究据此单独考察
P99–101 的按组能量补偿，采用同源分组表、P99 的噪声与正弦预算及 P100 的约 4 dB 上限。
该局部策略的实现与复现实验入口由受限研究档案保存。

## 历史结果及边界

局部实验检查了能量闭合、补偿上限、信号与噪声及正弦的共同缩放、分组来源和状态事务性。
原始验证结果及摘要见[实验记录](../experiments/aspx_limiter_off_boost_option.json)。
这些摘要和测试计数对应采集时的研究版本。

2026-10-16 的[独立对照](../ASPX_LIMITER_OFF_INVESTIGATION.md)中，
强纯音的 12–18 kHz 误差增加约 1.11 dB，音乐基本无变化。参考关闭分支另有分组约束、
硬上限和能量地板。局部补偿实验的结论限定于所测策略与输入。

默认语义的后续裁决继续依赖公开条款、独立数学性质、生产反例和回归验证。
