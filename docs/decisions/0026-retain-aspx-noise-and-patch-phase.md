# ADR-0026：保留 A-SPX 噪声与搬运的生产相位

日期：2026-11-08。状态：已采用；限定为本仓库的工程裁决。

## 决策

保留当前 P65/P66 QMF 定义、P102 噪声表乘法和 P89 跨子带搬运规则。测试中的
`noise_inverse_r`、`patch_ratio`、`noise_and_patch` 不进入产品默认，也不新增公共兼容开关。
已测参考与本地的固定相位差登记为**已解释的实现差异**，停止以降低该项参考波形误差
为目的的常规扩样。保留规范不确定性，不新增官方符合性声明。

这项裁决不改变 ADR-0019 的噪声时钟修复、ADR-0021 的注噪条件、ADR-0022 的预平坦化
方向、ADR-0023 的 TNA 求解、ADR-0024 的合并选择或 ADR-0025 的插值日程。

## 独立依据

本轮重新读取锁定的 [ETSI TS 103 190-1 v1.4.1](https://www.etsi.org/deliver/etsi_ts/103100_103199/10319001/01.04.01_60/ts_10319001v010401p.pdf)：

- `5.7.3–5.7.4` 的 P65/P66 定义 QMF 分析和合成。
- `5.7.6.4.3` 的 P102 以实电平乘复数 NoiseTable；`5.7.6.4.5` 的 P107 直接相加。
- `5.7.6.4.1.4` 的 P89 在同一 QMF 表示内搬运源带，没有另列逐带相位系数。

按本仓库已选的复数表列序合读这些接口，没有发现生产连接遗漏或重复了必要转换。
表 D.2 的两列说明仍不足以证明所有内部表示的唯一性；已有独立原语对照支持当前列序，
不能据此扩大为正式符合性结论。官方公开目录本轮仍列到 v1.4.1，没有取得要求另加该
旋转的官方澄清；不把检索未找到当作不存在的证明。

既有独立 FIR、解析载波和完整生产链的表示不变量继续作为依据。对基底变换
`Q'(k)=U(k)Q(k)`，同一物理算法要求搬运、生成分量及历史同时变换：

```text
T'(k,p) = U(k) T(k,p) / U(p)
N'(k,t) = U(k) N(k,t)
```

仅在当前生产基底内令噪声乘 `1/R(k)` 或搬运乘 `R(p)/R(k)`，会改变物理输出。
它们不是补上已证实丢失的无损表示转换。当前分析／搬运／合成的独立回归没有失败。

## 完整候选验证

冻结 `R(k)=-exp(i*pi*(k+0.5)/128)`，对 13 条新素材与 8 条旧音乐／纯音执行四组：
原默认、只改噪声、只改搬运、两项联合。共 84 次完整本地解码、16,600 AU；参考沿用
已有完整捕获，不新增参考运行时覆盖。没有调节相位、尺度、时延或对象排列来评分。

联合候选对新低／中码率素材的 12–18 kHz 误差能量改善约 18.32–26.50 dB，旧音乐
约 19.08–34.08 dB；这个结果支持固定相位模型的解释力。其全带包络、相关性、首尾和
高码率对照并非处处改善。即使所有分数改善，也不能替代上述独立纠错依据。

全部候选保持 core PCM、控制／时间轴和 LFE；默认经显式 Scene 单位往返后与既有 CLI
输出逐位一致。单位旋转覆盖全部实际复系数，包含次正规数误差预算，最大误差／界约
0.7062。六项普通 Rust 测试约束默认无操作、范围、旋转方向、分段及跨通道复积，
旋转方向和半子带原点另由 80 位 Decimal 独立锚点约束。
候选只由 ignored 测试驱动显式选择，退出作用域恢复默认，不进入 release 产品构建。

完整分数、检查命令、源摘要和失败／等价改写记录见
[候选调查](../ASPX_PHASE_CANDIDATE_INVESTIGATION.md)及其机器记录。

## 后续处理与重开条件

相位支线按本决策收口，后续关注生成信号、预平坦化与增益／噪声电平的耦合。旧音乐
的 18 位 preflat 单改控制保持同一参考 PCM；在联合相位诊断下，完整高频误差进一步
下降约 14.80 dB。但固定同一噪声／音调后，AU 100 只换 HF 或只换增益都会恶化，
两者一起换才改善约 5.25 dB。这不足以删除已有独立性质支持的预平坦化步骤。

重开本相位决策需要官方明确约定、独立于参考分数的生产反例，或新增且可验证的宿主
兼容性需求。重新裁决必须同时声明 QMF、跨子带算子、生成分量和历史的坐标，保留
完整默认对照；不能把一种物理算法变化描述成纯表示整理。
