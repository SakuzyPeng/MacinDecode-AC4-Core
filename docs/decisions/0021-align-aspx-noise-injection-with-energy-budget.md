# ADR-0021：实际注噪共用 A-SPX 能量预算条件

日期：2026-10-17。状态：已采用。

## 背景

`TS103190-1:v1.4.1:5.7.6.4.2.2` 的 P95/P99 在 onset 或正弦相关位置排除噪声预算，
但 P94/P101 仍可产生非零噪声电平，`5.7.6.4.3` 的 P102 与 `5.7.6.4.5` 的 P107
又无条件生成、叠加该噪声。原生产按后两处字面执行，实际输出会加入 P99 未计入的分量。

[独立调查](../ASPX_NOISE_MASK_INVESTIGATION.md)固定输入、增益和状态，在 936 个构造案例、
40 次真实调用的 67 个包络，以及交织／跨帧携带边界上验证了条件。参考行为是补充证据；
本次决策的独立依据是使能量配平与实际组装采用同一预算，不把参考吻合视为规范明文。

## 决策

在 `hfgain::adjust` 中按子带、包络保存 P99 的原始判定：

```text
noise_enabled[sb][env] = !sine_onset(env) && sine_level_before_boost[sb][env] == 0
```

P99 分母与 `hfassemble::assemble` 共用该值。onset 包络全部不叠加噪声；普通包络只抑制
非零正弦所在子带，同组其它子带仍可注噪。该条件适用于 `Off`、`OffWithBoost` 和 `On`
三种 limiter 模式；不改三张电平／增益矩阵、boost 运算及其顺序。

不能改用 `sine_area`，也不能从调整后正弦电平重新推断：前者会误抑制邻带，后者在极小值
乘 boost 下溢时可改变零／非零判定。生产内部保存布尔矩阵，不新增公共 API 或 CLI 选项。
这是默认算法修复，不改变既有 limiter-off boost 的默认值。

噪声和音调生成器继续生成全部时隙并推进原游标；音调初相仍为 1。只在当前区间新生成的
组装部分决定是否消费噪声，信号与音调照常叠加。越帧尾部保存处理后的成品，下一帧取回
时不再组装。预平坦化、QMF、TNA、交织支持范围及其它解码策略均保持原样。

这是对 P102/P107 无条件字面的本地判读补充，没有官方勘误依据。

## 原语验证

生产回归覆盖三个 limiter 模式、当前 onset 与上一间隔末尾指针、同组无正弦邻带、
多包络／奇偶子带、补偿后极小正弦下溢、结果复用清理及失败事务性。普通零 HF 输入仍
输出原噪声；相同输入的 onset 分支输出零，但生成的噪声矩阵和结束游标不变。

两帧携带测试直接使用生产门控：首帧 `[30,34)` QMF 时隙被抑制，`[32,34)` 原样进入
次帧 `[0,2)`。噪声仍消费 64 个时隙 × 20 子带，结束于 256；音调结束于 0。

缺陷注入分别恢复无条件叠加、漏掉 onset、按整个 harmonic 组停噪、改用 boost 后电平，
判据全部失败；交换正确谓词的判断顺序仍通过。保留历史 `literal`／`masked` 诊断，新增
`production` 路径直接使用预算掩码及未过滤的噪声输入。

936 个构造案例的新生产结果逐位等于前轮的 masked 结果，并经既有独立比较器复核参考。
全部 786,240 个有效实／虚分量的绝对误差、非零相对误差、ULP 和符号零位差均为零。
历史两模式和两个结束游标逐位保持，3,200 份固定增益输入的三个模式数值输出也逐位不变。
构造重放从调整后增益边界接入，预算判定本身另外由真实生产估计／增益链和压力夹具验证。

## 单项端到端影响

固定 LFE + 20 个对象的身份、`2^-16` 幅度尺度与已有 31 samples 整数延迟，比较全部 21 路
和完整对齐区间，包括尾部。没有拟合幅度、相位或延迟。下表为默认 boost 策略，误差改善
的正数表示误差能量降低；峰值变化的正数表示升高。

| 输入 | 全区间误差改善 | 12–18 kHz 误差改善 | 峰值变化 |
| --- | ---: | ---: | ---: |
| 原强纯音，limiter=1 | +0.000343 dB | −0.000822 dB | −0.184579 dB |
| 原强纯音，limiter=0 | +0.002322 dB | −0.000980 dB | +0.000019 dB |
| 独立音乐，limiter=1 | +0.021606 dB | +0.021101 dB | 0 dB |
| 独立音乐，limiter=0 | +0.021758 dB | +0.020524 dB | 0 dB |
| 128K 强音调 | +0.005847 dB | +0.007028 dB | −0.035611 dB |
| 18.1875 kHz 输入 | +0.008589 dB | +0.007233 dB | −0.000028 dB |

18.1875 kHz 主峰在固定频带范围之外，不用该频带评价主峰。另测了每份输入的显式 boost
路径；limiter=1 时开关仍逐位无影响，所有修复前后的 LFE 都逐位不变。原强纯音在 limiter=0
且显式 boost 下的峰值由 1.001554 变为 1.001557（按固定尺度），完整结果保留在机器记录。

修复消除了已隔离的预算外注噪；整段参考误差只略有改善，原强纯音的固定高频频带还略增。
局部重放逐位吻合不代表完整解码与参考吻合，也不等于可听改善。预平坦化、QMF 表示和音调
初相仍需分别裁决。

## 回归与基线

默认／audio-decode 测试分别通过 516／1,313 项，相关 Python 测试 139 项，两套 Clippy
通过 `-D warnings`，格式和层依赖审计通过。三层各 12 条基线中，Core 全部逐位保持；
A-SPX 和对象层各 12 条 PCM 摘要有意更新，所有采样率、声道数、帧数和轨道身份不变。
更新后重新导出并通过全部 36 条。

方法、输入／二进制摘要、完整误差与峰值、注入结果及逐条基线变更见
[`aspx_noise_mask_fix.json`](../experiments/aspx_noise_mask_fix.json)。大型 PCM、原始重放和专有
捕获留在核验卷身份的 cache 外置盘；本轮没有新增参考捕获，构建复用原 `target`。
