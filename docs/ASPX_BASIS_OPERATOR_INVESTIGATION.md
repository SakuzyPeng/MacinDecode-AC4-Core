# A-SPX 基底：跨子带搬运与音调合成的独立对照

日期：2026-10-16；生产起点 `40ea851`，参考 DRP 4.3.0.19350 arm64。
本轮只增加测试、比较工具和记录，生产 DSP、默认策略及 PCM 基线不变。
机器摘要见 [`aspx_basis_operator_comparison.json`](experiments/aspx_basis_operator_comparison.json)。

## 结论与边界

已有的 64 子带 QMF 接口换算 `R(k)=-exp(j*pi*(k+0.5)/128)`，现在进一步经过了跨子带
搬运和生成分量合成的独立检验。结果支持两项分别处理的差异：

- 在相同基底下，统一参考 HF 原语的固定四分之一尺度后，零预测项的搬运与本地生产
  `hf_generate` 完全一致。换基底后若复制系数仍为 1，则不是同一个物理算子；必须为每个
  源／目标对子带补上由 `R` 推导的相对相位。
- 固定 QMF 基底换算之后，音调相位再前移一项仍留下约 90° 差异。初相 1／0 无法全部解释为
  这套基底换算的记号差别；它仍是独立的时序／相位选择。

这不是更改生产 QMF 或初相的决定。真实流还用到 8／48 子带分析上下文，本轮没有把这些路径
全部转换为同一已验证表示，也没有做新的完整对象 PCM 算法 A/B。

## 固定输入与有效捕获

复用已验证的 HF 和组装原语，在完整 decoder 关闭后，对输入和状态的自有副本做实验。
每份配置各有两个独立进程，全部 AU 成功、参数设置成功、样本有限，插桩 PCM 的摘要与既有
未插桩参考相同；HF、逐包络组装及结束游标仍能逐位重放。

| 输入 | 全段 AU | 捕获 AU | 实际 HF 调用 | 包络 |
| --- | ---: | ---: | ---: | ---: |
| 原强纯音 | 143 | 8 | 9 | 9 |
| 独立 768K 音乐 | 400 | 100 | 9 | 23 |
| 128K 音调 | 143 | 3 | 2 | 4 |

上述 20 次调用每次增加真实输入／构造输入、原表示／除以 `R` 的四种参考重放，共 80 份
HF 结果；两次独立捕获的相关矩阵逐位重复。构造输入使用确定的有限复数序列，所有 TNA 模式
和 chirp 历史归零、关闭预平坦化，隔离纯搬运；真实输入实验保留原来的全部参数与历史。
20 个调用衍生出 4 种不同的构造输入／区间／布局条件，不将重复布局算作新的参数覆盖。
内部调用号也不作为最终对象 PCM 的路号。

三个实际布局分别为：

| 目标边界 | 每段源起点 | 基底变换对应的固定相位 |
| --- | --- | --- |
| 36 → 44 → 62 | 28、18 | −11.25°、−36.5625° |
| 36 → 44 → 56 | 28、24 | −11.25°、−28.125° |

`xover` 是数据侧参数，不能由配置侧字段随意补 0；128K 样本的交叉子带为 34。测试入口按捕获

来自已验证的完整解码状态。初期沿用零交叉偏移的夹具被这些检查拒绝，未计作解码算法差异。

## HF：尺度与相位分别计量

原语构造结果确认，在预测项关闭时，参考边界执行：

```text
H_ref(q)[k] = q[p] / 4
```

本地生产的同一退化路径为 `H_local(q)[k] = q[p]`。这里只为比较该接口乘以 4，不改变生产
增益，不把它当作对象 PCM 的缩放，也不推断整条 HF／增益链都应增加或减少 12 dB。
20 个同输入案例的 30,496 个实／虚分量，在同基底及旋转后同输入两种控制下均逐位一致。

现在把参考表示转换到本地表示，设 `q_local[p]=q_ref[p]/R(p)`。参考输出在本地表示中应为：

```text
4 * H_ref(q_ref)[k] / R(k)
    = (R(p)/R(k)) * q_local[p]
R(p)/R(k) = exp(j*pi*(p-k)/128)
```

因此，把输入除以 `R(p)` 后仍直接复制，遗漏的是确定的 `R(p)/R(k)`，不是待拟合的增益。
它与[相位契约](ASPX_PHASE_CONTRACT.md)中反向换表示的 `R(k)*T(k,p)/R(p)` 互为对应。

| 固定同一物理输入的比较 | 全部目标子带的 SNR | 最大绝对差 |
| --- | ---: | ---: |
| 仅换输入表示，复制系数仍为 1 | 4.39–8.04 dB | 1.939307 |
| 同时按源／目标变换复制系数 | 147.02–147.22 dB | 2.3842e−7 |

两行都包含完整生成区间，差异由固定公式决定，未调整时间、频带或从输出拟合相位。第二行不是
逐位一致：两次浮点旋转仍有舍入差；ULP、相对误差和绝对误差在机器记录中分别保留。

真实输入及其四行历史一起除以各自的 `R(p)`，参考 HF 输出同样符合按**源**子带旋转的预测。
20 次真实调用中 13 次有非零输出：2 次数值精确一致，其余 11 次为 132.02–142.22 dB SNR；
7 次静音不算相位证据。这只验证该原语对基底变换的行为，不是本地完整 TNA 已与参考逐位一致。

## 音调：固定基底之后，初相差异仍存在

在零 QMF、零信号增益与零噪声下，用参考组装原语逐个激活 64 个子带，覆盖初始索引 0 和 1。
每例保留 3 个前置零时隙、29 个音调时隙及 16 个尾部零时隙，再送入零历史的参考合成器。
共 128 例、393,216 个 PCM 样本，保留整个区间和合成尾部，没有带宽掩码或延迟搜索。

本地使用同一份已归一化 QMF 输入直接调用生产 `synthesise`，只在测试端应用固定基底换算
或表相位推进。参考生成器先前已与生产发生器独立核对；本步检验的是生成分量到合成输出的
连接，不冒充完整码流的生产 A/B。

参考音调 QMF 的单位为 `2^-23`，参考合成接口另有固定 `64` 倍关系，因此本实验参考 PCM
采用 `2^23/64 = 2^17` 换算。它不替换对象 PCM 的 `2^-16` 比较尺度。

| 本地合成输入处理 | 128 例 SNR 范围 |
| --- | ---: |
| 同一表相位，保持本地原基底 | −6.02 至 −3.06 dB |
| 保持本地原基底，表相位前移一项 | −6.02 至 28.68 dB |
| 除以 `R(k)`，同一表相位 | **139.58 至 142.89 dB** |
| 除以 `R(k)`，再前移一项 | −3.013 至 −3.007 dB |

这补足了偶数子带在**原语连接**中的构造覆盖；不依赖先前被参考终端带宽抑制的 18.1875 kHz
码流主峰。真实码流上的偶数音调路径仍须另行捕获，不能拿合成构造替代。

表相位前移一项等价于复数乘 `j*(-1)^k`。而 `R(k)` 随子带变化，两者不是同一个旋转。
对参考索引 0 的子集，本地索引 1、原基底相对于统一后的参考分量，其相位比为：

```text
j*(-1)^k * R(k)
```

例如子带 36 为 −38.671875°，子带 37 为 +142.734375°。某些子带偶然接近并不能覆盖其它
子带；这也解释了为何只看一个被编码器激活的音调，容易把两种问题混在一起。

## 验证、复现与后续

本地入口为忽略测试 `replay_basis_checkpoints`，只显式接收离线矩阵和新输出目录。H 案例
逐项校验频带与 patch，S 案例固定矩阵形状；比较器另拒绝遗漏／重复身份、错位区间、错误
音调输入、非有限数据、越界写入和缺失模式。参考行为、数值量级和规范裁决分开记录。

```bash
MACINAC4_BASIS_REPLAY_INPUT=/absolute/path/cases.txt \
MACINAC4_BASIS_REPLAY_OUTPUT=/absolute/path/new_local_basis \
cargo test -p macindecode-ac4-decode --features audio-decode \
  replay_basis_checkpoints -- --ignored --nocapture
python3 scripts/check_aspx_basis_replay.py /absolute/path/cases.json \
  /absolute/path/normalized_inputs /absolute/path/new_local_basis \
  --output /absolute/path/new_comparison.json
python3 -m unittest scripts/test_check_aspx_basis_replay.py
```

H 输入的配置末项允许 `255`，明确表示 `xover` 尚需按捕获的交叉子带唯一恢复；它不是实际
码流值。频带配置、输入历史和有效写入区间不能按案例名猜测。原始捕获、专有适配器及地址
留在经身份核验的外置 `cache` 实验目录；仓库只保存方法、公开测试和摘要。

默认／audio-decode 测试分别通过 516／1,300 项，相关 Python 47 项、两套 Clippy、格式和
层审计通过。36 条 PCM 基线逐位不变；生产数值代码、release 二进制及受保护文件摘要
均保持不变。

下一步优先捕获真实 **8／48 子带分析路径**的输入、输出与历史，确认其到 A-SPX 低带输入的
相位、尺度和时间映射。该处闭合后，再决定生产 QMF 与生成分量应采用哪种共同表示；当前
不能把端点旋转、patch 系数和初相整体作为已获证实的生产修复。
