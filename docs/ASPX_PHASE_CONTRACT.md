# A-SPX 相位比较契约

日期：2026-10-01；更新：2026-10-17。状态：**诊断比较约定已固定；未决定替换生产 QMF 或初相**。
本文件把[剩余项调查](ASPX_REMAINING_INVESTIGATION.md)使用的基底、时钟和评分边界明确分开，
避免把不同实验混记成一次修复。

## 生产基底与参考观察模型

生产低层 QMF 保持 `TS103190-1:v1.4.1:5.7.3–5.7.4` / P65/P66：

```text
omega_k = pi*(k+0.5)/64
analysis:  exp(j*omega_k*(n-0.5))
synthesis: exp(j*omega_k*(n-127.5))
```

诊断模型固定 `R(k) = -exp(j*omega_k/2)`：分析输出乘 `R(k)`，经过 A-SPX、A-JOC 后，
终端合成输入乘其逆。中间的 patch、噪声及音调代码按各次实验声明执行。它是一个会改变
生成分量 PCM 的算法变体，不能称为全局延迟修正或无损重构。

| 项目 | 当前生产 | 联合诊断中固定的观察模型 |
| --- | --- | --- |
| QMF 基底 | P65/P66 字面 | 分析后乘 `R(k)`，终端合成前除以 `R(k)` |
| 噪声区间起点 | 已按 ADR-0019 换算到 QMF 时隙 | 换算到 QMF 时隙 |
| 音调区间起点 | 已按 ADR-0020 换算到 QMF 时隙 | 换算到 QMF 时隙 |
| 音调初始索引 | 1 | 0；发生器与合成原语构造已覆盖奇偶，真实偶数路径仍待补足 |
| 预平坦化 | P85/P89 字面 | 单独声明 literal、地板候选或 bypass，不能隐含 |
| TNA 预测器 | ADR-0017 的减号 | 相同，不能再记一次修复收益 |

这张表描述已测行为，不推断参考库内部函数的实现位置。

2026-10-04 的[内部检查点实验](ASPX_REMAINING_INVESTIGATION.md#2026-10-04已打通内部-qmf-检查点与独立重放)
进一步直接验证了 64 子带原语的接口关系：`A_ref = R*A_local/128`、
`S_ref(q) = 64*S_local(q/R)`，误差为浮点数值量级。196 个固定换算案例以及真实合成检查点重放
均已复核；真实检查点还保留了原生历史状态。它将 `R` 从端到端候选提升为已验证的特定内部
边界约定，仍不意味着所有 A-SPX 中间算子已匹配，也不改变生产相位或对象 PCM 的比较尺度。

## 基底变换不等于保持中间算子不变

若只是给同一物理算法换表示，跨子带算子和生成分量也必须一起变换。设旧算子将源子带 `p`
乘系数 `T(k,p)` 后搬到目标 `k`，则新基底中的同一算子应为：

```text
Q'(k) = R(k)*Q(k)
T'(k,p) = R(k)*T(k,p)/R(p)
noise'(k,t) = R(k)*noise(k,t)
sine'(k,t)  = R(k)*sine(k,t)
```

同时变换这些量，再在出口乘逆，才在数学上保持原物理 PCM；浮点实现仍需单独记录舍入差。
现有诊断把 patch 的复制系数保留为 1，因此产生：

```text
R(p)/R(k) = exp(-j*pi*(k-p)/128)
```

跨度为 8、20 个子带时，分别改变 -11.25°、-28.125°。同子带直通的两端旋转会抵消，
所以纯 QMF 往返测试不能发现这种跨工具差异。噪声/音调若不随基底旋转，也会改变物理相位。

`R` 和 `-R` 可通过让生成分量同时反相而得到相同 PCM。这种等价性意味着黑盒输出不能
唯一确定全局负号落在哪个内部函数。[代数检查](../scripts/check_aspx_phase_basis.py)锁定上述
关系，不加载规范窗表，也不声称已经测试生产滤波器。
上述不可辨识性针对仅观察末端 PCM；新增原语实验已固定本次所取 QMF 边界的符号，其他内部
边界仍须各自声明表示，不能继续任意移动这个负号后混用检查点。

## 时间轴与初相分别裁决

所有区间边界先标明 ATS 或 QMF 单位；在生成循环中使用
`origin_qmf = atsg_sig[0]*num_ts_in_ats`、`relative_slot = ts-origin_qmf`。
在既有标量 previous 游标语义下，恒定包络的全局生成序列应不因跨帧分界改变而额外跳号。
[整数时间轴检查](../scripts/check_aspx_cursor_timeline.py)刻画这一性质。

这条时钟要求不决定初始索引。将初始索引从 1 改成 0 是额外的相位选择，必须单独记账。
早期末端数据以奇数子带为主；18.1875 kHz 的偶数子带被参考严重衰减。后续直接原语构造
已覆盖 64 子带的发生器／合成连接，但真实偶数路径仍待补足。数学上支持起点换算，也不能
据此声称整条生产链已经与参考一致。

## 比较与后续实现的边界

- 物理轨道身份由描述符固定。尺度统一使用已说明的 `2^-16` 比较换算，整数时延须有当前
  输入的独立依据；不得逐轨重排、拟合增益或调整延迟来评分。
- 全部轨道及整个共同 PCM 区间保留统计。12–18 kHz 是既定参考频带；带宽之外的观察单列，
  不把参考停止带当作本地解码目标。
- 每次实验明确记录基底、两个起点单位、音调初相和预平坦化模型。原生单项变更、联合诊断、
  纯代数模型分别计分；高相干性与完全一致不是同一结论。
- 生产若采用不同基底或生成相位，必须另作明确决策并重跑受影响基线。不能通过改名、加一层
  旋转或把模式藏在内部，让一次 PCM 算法变化看起来只是表示调整。

当前未新增兼容模式或公共选项。剩余决策是如何解释规范相位与参考行为的分歧；这个比较契约
为该决策提供可复现的实验边界，不用单个 runtime 的吻合度代替规范裁决。

## 2026-10-16：噪声时钟与列序获得独立证据

[噪声原语对照](ASPX_NOISE_CURSOR_INVESTIGATION.md)已验证 464 个相同输入案例：生产字面式
有 128 个结束游标不符，换算起点的诊断模式全部对齐；416 个可辨识案例的复数噪声逐位一致。
真实音乐 AU 33 的非零左边界也对应额外 60 项跳号。该边界支持现有表 D.2 的实虚列序；
没有改变生产 QMF 基底、噪声公式或音调初相，也没有把符号零等价写成全缓冲逐位相同。

随后按 [ADR-0019](decisions/0019-correct-aspx-noise-origin-time-unit.md)仅将噪声起点换算
应用到生产；QMF 基底、音调初相及预平坦化保持原样。生产重放复现此前诊断结果，但独立音乐
的端到端高频误差仍增大约 2.89 dB，因此局部时钟匹配与末端差分继续分开计分。

## 2026-10-16：跨子带系数与音调合成获得独立验证

[基底算子专项对照](ASPX_BASIS_OPERATOR_INVESTIGATION.md)在三个实际 patch 布局上确认：
参考零预测项的 HF 原语有固定 1/4 接口尺度；统一尺度后，本地纯搬运逐位吻合。将参考表示
转换到本地表示时，系数需为 `R(p)/R(k)`。只旋转输入、保留复制系数 1 的差异可直接观察，
同时变换算子后为约 147 dB SNR 的数值残差。

128 个单子带生成／合成构造覆盖全部 64 子带与两个初相，固定 R 换算后为 139.58–142.89 dB
SNR；再前移一个音调表项仍留下约 90° 差异。初相 1／0 不能全部解释为 R 的表示差别。
生产音调起点已经按 ADR-0020 修正，但初相和 QMF 仍未改；下一项是实际 8／48 子带分析
上下文及其到 A-SPX 低带输入的边界，不能把 64 子带原语结论直接覆盖到这些路径。

## 2026-10-17：实际可变宽度分析与低带交接已捕获

[分析边界报告](QMF_ANALYSIS_BOUNDARY_INVESTIGATION.md)验证了实际 8／48 子带分析的输入、
各级中间量和历史。参考分析输出到 A-SPX 低带及 LFE 合成入口均仅有 6 个时隙的延迟，
尺度为 1，未发现额外旋转。这里没有用波形相关性重排来源。

对使用捕获窗的可变 N 诊断推广，理想关系为：

```text
C_N(k) = -exp(j*pi*(k+0.5)*(1/N - 1/128))
A_ref,N ≈ C_N(k) * A_N / (2N)
```

N=64 恢复本契约原有 R64；N=8／48 还含输入采样间隔相关的补偿。48 带实际后旋转表与
理想角度的微小差别，以及 FFT 的数值残差，已经分开计量。可变 N 公式只是诊断模型，未
变成生产滤波器，也不改变此前跨子带算子必须一起换表示的结论。

公共解析波形的半采样网格虽然改善了对应关系，但 8／48 与 64 分支仍分别只有约 25–27／
48–54 dB SNR，不能宣布完整路径等价。下一步是实际 ASF／IMDCT 输出到 QMF 输入的采样
位置、有效采样率与历史；生产 QMF、初相和比较尺度继续保持既有决策。

### 同日续查：ASF 输入的尺度和时间轴已固定

[ASF／IMDCT 检查点](ASF_IMDCT_BOUNDARY_INVESTIGATION.md)支持
`X_ref = X_local/(M*65536)`，其中 M 是码流原始块长；参考采用未归一化的较短余弦变换。
其采样位置为 `t_48k=(i+0.5)*64/width-0.5`，另有表 188 的 352 个 48 kHz 样本延迟。
这些约定能解释主声道和 LFE 的真实 QMF 输入及短块历史，频谱约 146 dB、PCM 约 120–140 dB
SNR。原生变换重放逐位一致，数学模型的主要细差已定位到 FFT 步骤。

本轮内部 64 宽控制相对生产 Core PCM 使用 `2^-17`，因为 Core 出口另有 `2/M` 因子。
这不替换对象 PCM 的 `2^-16`，也不改本契约的 R64、跨子带算子或音调初相决策。下一步应
固定这套真实 ASF 输入再比较不同宽度 QMF，不继续把相位差归因于未知前端采样位置。
