# A-SPX 实际链能量联动与 P94 精度修复

日期：2026-11-08；基于 `ebf188a`，接续
[相位候选裁决](ASPX_PHASE_CANDIDATE_INVESTIGATION.md)。
机器记录见 [aspx_energy_budget.json](experiments/aspx_energy_budget.json)。

本轮修复了一处有独立反例的 P94 数值问题；正常素材的预平坦化、增益和噪声电平
联动则符合现有方程。主高频残差没有因此消失，生产相位和预平坦化策略保持。

## P94：功率先下溢，幅度仍可表示

`S=2^-126, Q=2^-24` 时，旧 f32 噪声功率先舍入成零，开方无法恢复应有的
`2^-75` 幅度。`S=2^-126, Q=64` 时，中间分配因子仍非零但精度不足，噪声电平
偏离独立锚点 32 ULP。两例的输入均通过实际包络差分解码和反量化 API 得到，
100 位 Decimal 独立求平方根并按最近偶数舍入；没有用本地 `sqrt` 生成预期位型。

[ADR-0027](decisions/0027-preserve-aspx-small-power-amplitudes.md)采用局部 f64 回退：
只有中间因子／功率进入次正规范围或为零时重算受影响的幅度。常规舍入保持。
两个反例在旧实现上失败、修复后通过；另覆盖正规输入的 1,778 组功率预算和跨边界连续性。
这些是已接受 API 输入的反例，不等于新增真实编码向量或官方符合性证明。

## 实际链观察与独立核对

扩展现有 `cfg(test)` 分量观察器，在 P90/P94 出口及 P95–101 出口记录实际矩阵、
信号与 limiter 分组、onset 和噪声游标。增益记录必须由同一次组装消费，组装结果
再与实际输出源逐位绑定。观察器不更改产品路径、公共 API 或 CLI JSON。

`check_aspx_energy_budget.py` 对七个窗口逐一执行：

1. 由实际 `Q_high` 求区域平均，核对 P90；独立核对 P94 功率分配。
2. 从实际输入计算 P95 初始增益、P96 上限、P97 噪声限幅和 P99–101 boost。
3. 用已冻结表 D.2、实际前后游标及最终电平重建全部噪声；onset 仍推进生成器。
4. 按 f32 乘法、条件注噪和音调相加的顺序重建实际组装，要求逐位相同。
5. 分开统计目标预算、信号／噪声／音调能量、交叉项、区域平均与乘法舍入差，以及
   最终加法舍入。有限窗口的实际能量不被强制归一到目标。

P90 的误差界固定为 `2 × f32::EPSILON`；幅度／增益链为至多八次 f32 舍入的前向界，
不按观察到的残差调阈值。噪声和组装要求位型相同，包括符号零。音调在此核对功率，
完整初相仍由既有音调判据负责。

| 输入／AU | 实际调用 | 信号包络 | 被限幅的子带包络 | boost 达上限的组 |
| --- | ---: | ---: | ---: | ---: |
| dense PRBS L4 448K／171 | 7 | 14 | 4 | 0 |
| transient edges L4 256K／4 | 5 | 14 | 54 | 3 |
| tone1／8 | 9 | 9 | 5 | 16 |
| tone0／8 | 9 | 9 | 0 | 不进入 boost |
| music1／100 | 9 | 23 | 81 | 0 |
| music0／100 | 9 | 23 | 0 | 不进入 boost |
| music_preflat0／100 | 9 | 23 | 85 | 2 |

合计 **57 次调用、115 个包络、2,716 个子带包络**。P90 最大相对差 `5.77×10^-8`，
P94 为 `3.64×10^-8`；由矩阵边界重算的最终 signal/noise/sine/boost 全部与采集值相同。
实际噪声和组装全部逐位一致。17 个 onset 包络被覆盖；这批窗口没有活动正弦，
interpolation 均为 true，P94 精度回退也均未触发。这三项的其它分支由构造回归覆盖，
不扩大真实素材覆盖声明。

统计窗口是一次 A-SPX 调用的完整生成区间，包括留给下一帧的尾部成品，不包括从上一帧
取回的前缀。`32 ≤ k < 48` 在 48 kHz 对应 12–18 kHz，下面只统计它与实际 A-SPX
生成区间的交集。窄频段不一定覆盖完整 limiter 组，不能要求其预算独立等于目标。

## 预平坦化如何改变噪声

music1 与 music_preflat0 只差已验证的 18 个 preflat 位。AU 100 的目标 `S`、噪声比
`Q`、分组、onset、注噪掩码、游标和 P94 初始电平全部相同；core、A-JOC 元数据及
整数时间轴也相同。诊断仍使用生产相位，没有重跑参考库或采用相位候选。

令 `G0` 为 P95 初始增益、`C` 为 P96 上限、`N0` 为 P94 噪声电平，则忽略矩阵边界
舍入时：

```text
r = min(1, C / G0)
G_final = G0 × r × B
N_final = N0 × r × B
```

预平坦化改变各子带的 `E`，于是同时改变 `G0` 和整组上限 `C`；噪声先按同一损失
比例下调，再随组内 boost `B` 补偿。该窗口按各自 `sqrt(E)` 归一化后的两份生成
信号，相对 L2 差仅 **3.02×10^-8**。主要变化是幅度经过分组限幅和补偿后的分布，
没有观察到新的生成信号形状差异。

在 12–18 kHz 交集的 276 个子带包络中，受限数从 75 变为 79；关闭 preflat 后：

- 最终噪声幅度比范围 **0.6830–1.3963**，5%／95% 分位为 0.8472／1.0465。
- 按实际时隙长度加权，噪声幅度变化的相对 L2 为 **4.3004%**。
- 噪声总预算只下降 **0.8505%**，总能量接近不能证明逐带电平相同。

再用对称乘积恒等式把幅度变化拆成限幅比例项和 boost 项：

```text
ΔN = N0 × Δr × (B0+B1)/2 + N0 × ΔB × (r0+r1)/2
```

两项的加权平方和分别为 `2.23405×10^6`、`3.03086×10^5`，交叉项为
`−1.12843×10^6`；合成实际差值能量约 `1.40871×10^6`，出口舍入残差平方和约
`1.05×10^-6`。两项明显相消，不能把各自平方和除以总误差当作独立贡献百分比。
这是代数分解，不把对称分配约定包装成唯一因果归因。

## 能量预算与有限窗口输出

下表按时隙长度加权，并除以相同区域的目标能量；正弦项均为零。

| 12–18 kHz 交集 | 信号模型 | 噪声模型 | 实际交叉项 | 实际组装 |
| --- | ---: | ---: | ---: | ---: |
| music1 | 0.687550 | 0.292469 | −0.044372 | 0.935647 |
| music_preflat0 | 0.679632 | 0.289982 | −0.043044 | 0.926570 |
| music0（limiter off） | 0.702980 | 0.297020 | −0.044141 | 0.955858 |

完整 A-SPX 频段的 music1 模型预算为目标的 `0.99999998`，实际输出为 `0.950992`；
约 4.9% 的差主要来自有限窗口的信号／噪声交叉项。噪声表每个复数的功率范围约
`0.99999863–1.00000130`，所测音乐窗口的噪声实际功率与模型相差目标的约 `2.3×10^-8`。
本例不能用“有限窗口噪声功率偏低”解释那 4.9%，也不能因此放大 gain 或修改 EPSILON。

tone0 的模型预算只有目标的约 85.3831%，与当前 off 分支保留 P95 的 `E+1`、跳过
boost 一致。tone1 的 16 个饱和组大多承载很小的目标能量，不能只按饱和组数判断
整体缺口。参考 off 分支的不同策略仍沿用已有独立记录，未在本轮修改。

- `cargo test --locked --workspace --features audio-decode`：1,336 通过、44 ignored。
- `cargo test --locked --workspace`：514 通过、3 ignored。
- 全部 Python：525 通过，其中新能量检查器 14 项反例／代数控制；已接入 CI。
- audio-decode Clippy、`thumbv7em-none-eabi` 的 Scene `no_std`、格式与层边界检查通过。
- 三层各 12 项已冻结 PCM 基线全部逐位一致；21 条完整调查流共 4,150 AU 的对象与
  core PCM、时间轴及帧元数据保持，仅采集窗口选择标记按本轮 AU 改变。

默认无参数 `decode_check.py` 扫描会额外发现另一路新增的 13 条可解码但未登记输入，
因此整轮返回失败；23 条未支持的 channel-based 路径按原策略跳过。本轮保留该失败
日志，随后明确选择三份基线声明的全部输入验证 36 项，没有更新基线或把默认扫描
结果改称通过。新增 13 条 A-JOC 流均包含在上述 21 条完整提交前后对照中。

实验复用仓库 target；原始 QMF、PCM、可执行文件和日志保存在
本地受限研究档案，记录输入、工具和结果的 SHA-256。
正式 release CLI 已恢复原摘要，三份基线和规范清单均未变。机器记录固定源码、输入、
测试二进制、噪声表及完整审计输出的摘要；仓库不包含原始素材或规范表。
