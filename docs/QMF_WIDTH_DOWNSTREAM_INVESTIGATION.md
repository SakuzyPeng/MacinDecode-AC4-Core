# QMF 宽度差异在当前 A-SPX 下游中的传播

日期：2026-10-20；生产起点 `7394c44`。本轮只增加测试入口与检查器，不改变生产 DSP、
公共 API、CLI 或 PCM 基线。机器摘要见
[`qmf_width_downstream_comparison.json`](experiments/qmf_width_downstream_comparison.json)。

## 结论

已把[宽度调查](QMF_WIDTH_INVESTIGATION.md)的固定输入接到当前生产
TNA → 预平坦化 → 包络估计 → 增益 → 噪声／音调生成 → 组装，并保留各自的状态。
这批输入没有暴露新的生产数学或交接错误。不同分析宽度带来的微小时间中心、响应及泄漏
差异会保留到生成的 HF 中，包络补偿不会消除全部复数差异。

三种 limiter 模式、插值开／关、预平坦化开／关全部保留。相对参考分析输入的四种对照中，
只有一个子带包络改变了分组限幅状态；没有硬上限、boost 上限或估计能量跨过 1 的变化。
这里 `E < 1` 只标记 P95 的加性地板相对显著，**不是另一个代码分支或截断规则**。

这不是用参考分数选择新 QMF 算法的依据。生产仍保留已有 64 带路径和相位；
下表中的 A 也运行同一本地下游，不是 DRP 的最终 HF 或对象 PCM。

## 固定输入、表示与覆盖

复用已通过完整捕获门禁的强纯音 AU 8、音乐 AU 100 和 AU 33；没有新运行参考解码器。
保留 27 次调用、50 个真实信号包络，包括 7 次静音调用。调用号与最终对象号不同。
8 带 LFE 不经过这条 A-SPX 链，本轮不增加它的下游覆盖。

| 标记 | 低带输入 |
| --- | --- |
| D | 同一 Core PCM 的生产 64 带分析 |
| C | D 加入已推导的 1/6 样本时间中心对齐 |
| B | 同一 PCM 在居中网格取样，再通过独立脉冲测得的 48 带算子 |
| E | 同一本地频谱经较短 IMDCT／窗模型，再通过同一 48 带算子 |
| A | 真实捕获的 48 带分析输出 |

C、B 都另跑 1025 抽头插值，主对照沿用 513 抽头。没有按当前结果调整插值参数。
五种输入及两个收敛控制先统一到生产表示：

```text
Q_local = Q_common / R64(k) * 2^23
```

这是既有分析接口 `R64/128`、内部 PCM 的 `2^-17` 和 ADR-0006 的 2 倍接口因子
共同确定的换算。D 另与直接取原生产分析结果乘 `2^16` 核对，最多 1 ULP；各变体统一
采用同一条转换路径。不能再把内部 `2^23` 或旧 HF 原语的 `×4` 当成对象 PCM 尺度。

每个变体取完整 38 时隙低带及其前四个时隙的 TNA 历史。A 的这两部分分别与既有 HF
捕获逐位核对；频带、patch 源／目标和时间边界按记录身份固定，没有相关性匹配。
HF 源带并集分别是 18–35、24–35，不按能量删除弱带。

chirp、目标能量、噪声比例和正弦状态固定为已有归一化检查点。P90 能量由本次 HF 实际
计算，随后接入固定控制，再调用生产增益和组装；没有把旧的参考估计能量送回链中。
这是控制元数据 seam 的实验，不声称重放了之前所有 AU 的元数据解码／反量化。
各变体的噪声／音调游标共同从 0 开始；这个受控初值不冒充真实捕获区间的全部先前状态。

共 7 种输入 × 27 次调用 × 2 种插值 × 2 种预平坦化 × 3 种 limiter = **2,268 条链**，
覆盖 **4,200 个真实区间包络变体**。当前真实窗口没有活动音调，音调初相及真实偶数音调的
覆盖没有增加。

## 逐段结果

以下使用生产预平坦化、逐子带估计和 limiter=1，汇总每份材料的全部 9 次调用及完整
有效区间。每一列都以该阶段自身的 A 路能量作分母；SNR 不相加，也不把阶段间的 dB
变化当作最终 PCM 的改善量。

| 输入：D 对 A | HF 源带 | 生成 HF | 补偿后的信号分量 | 组装 HF |
| --- | ---: | ---: | ---: | ---: |
| 强纯音 | 53.95 dB | 54.58 dB | 53.39 dB | 53.39 dB |
| 音乐 AU 100 | 51.32 dB | 50.55 dB | 50.16 dB | 51.72 dB |
| 音乐 AU 33 | 51.40 dB | 49.55 dB | 49.44 dB | 51.39 dB |

阶段间既有相对误差增大，也有抵消或被共同噪声能量稀释的情况。检查器同时保存绝对误差、
非零分母相对误差、ULP、信号分量和组装结果，避免只看混合输出。
纯音部分预测系数的相对差异更大，但其固定 chirp 为零，不能把未被消费的系数差异说成
该段 HF 的误差来源。

| 组装 HF 对 A | D：64 带 | C：时间中心对齐 | B：同源窄带算子 | E：较短 IMDCT |
| --- | ---: | ---: | ---: | ---: |
| 强纯音 | 53.39 dB | 87.60 dB | 89.30 dB | 128.09 dB |
| 音乐 AU 100 | 51.72 dB | 70.43 dB | 92.90 dB | 105.33 dB |
| 音乐 AU 33 | 51.39 dB | 89.08 dB | 104.64 dB | 123.30 dB |

音乐 AU 100 的 C 对照逐调用组装 SNR 为 **64.48–74.76 dB**。因此此前全带较高的
83–94 dB 不能覆盖弱 HF 源带问题；其响应和泄漏差异确实传播到了组装出口。
E 的剩余差异也未归零，仍包含前端数值和测得算子的有限精度。

改变 limiter 模式并未消去这些差异。D 对 A 的组装结果如下，仍固定插值和预平坦化：

| 材料 | Off | OffWithBoost | On |
| --- | ---: | ---: | ---: |
| 强纯音 | 52.48 dB | 52.48 dB | 53.39 dB |
| 音乐 AU 100 | 51.70 dB | 51.70 dB | 51.72 dB |
| 音乐 AU 33 | 51.46 dB | 51.46 dB | 51.39 dB |

这些是现有三个本地模式的受控对照，不是码流开关的端到端收益。

## 唯一的分组限幅切换

音乐 AU 100、调用 0、包络 3、QMF 时隙 `[24,36)`、绝对子带 36：

| 量 | A 输入 | D 输入 |
| --- | ---: | ---: |
| 估计能量 | 2,897,413.75 | 2,893,622.25 |
| 初始信号增益 | 0.98237884 | 0.98302221 |
| 分组上限 | 0.98296672 | 0.98298985 |
| 初始增益／上限 | 0.99940193 | 1.00003290 |
| boost | 1.00000012 | 1.00000560 |
| 最终信号增益 | 0.98237896 | 0.98299533 |

一边低于上限约 0.060%，另一边高约 0.0033%；最终增益相差约 **0.063%**。
`min(initial, maximum)` 在交界处连续，这个布尔状态切换没有表现为大幅跳变。
其余分组约束仍会改变敏感度，即使没有新增“受限／不受限”切换；不能由切换数少推断
limiter 对谱形完全无影响。

组装的实际有限区间能量独立分成信号、噪声和交叉项并闭合。P99 使用的平均能量预算另列；
不要求一段确定性噪声与 HF 的交叉项恒为零，也不要求每个短包络的实测总能量严格等于目标。

## 连续性、检查器与限制

每条链追加一个**构造后续区间**：重复最后 32 个分析时隙，使用末包络控制但不重复 onset，
其左边界接住前一区间实际产生的 HF 尾部。它保留本地 TNA 历史、噪声／音调游标和合成
历史；检查尾部逐位交接及原始低带不被回写。这个构造不是下一真实 AU。

受控低带在 `sb ≥ sbx` 置零，再通过生产合并器和合成器记录两段诊断 PCM。该记录故意
隔离低带与新生成 HF，没有包含原分析高带的过渡带泄漏，也未进 A-JOC，合成从零历史开始；
**不能称为完整 A-SPX／对象 PCM 或听感评测**。9,289,728 个诊断 PCM 样本另外由独立
640 抽头合成 FIR 核对。

独立检查使用原始时序的增广最小二乘核对 TNA、三阶最小二乘核对预平坦化、时频平均
核对估计、固定能量公式核对增益，以及样本级组装和连续 FIR 核对后两段。
各量纲分别计分。15 项无媒体检查器测试含错误源带、陈旧能量、错误预测器、旧预平坦化
符号、噪声错位、清零历史、丢失尾部、遗漏包络和非有限值注入；完整正向及无损等价控制通过。

```bash
MACINAC4_WIDTH_CHAIN_DATA=/absolute/path/inputs \
MACINAC4_WIDTH_CHAIN_OUTPUT=/absolute/path/fresh-output \
cargo test -p macindecode-ac4-decode --features audio-decode \
  replay_qmf_width_downstream -- --ignored
python3 scripts/check_qmf_width_downstream.py \
  /absolute/path/manifest.json /absolute/path/inputs /absolute/path/fresh-output \
  --output /absolute/path/new-comparison.json
python3 -m unittest scripts/test_check_qmf_width_downstream.py
```

默认 516、audio-decode 1,328、spec-tables 107 项测试及 102 项相关 Python 检查通过；
两套 Clippy、rustfmt、层审计和 A-SPX 数学检查通过。三份 PCM 基线文件、既有正式二进制
和受保护用户文件摘要保持不变，本轮没有重新导出 36 条基线。
原始数据留在已核验身份的 cache 卷；公开仓库只有方法、测试和汇总。

下一步可以把当前受控测试扩展到**原分析高带泄漏与新生成 HF 的合并**，再考察实际 A-JOC
输入。当前结果支持把已解释的宽度差异与尚未覆盖的合并贡献分开，不支持直接替换生产 QMF。
