# 8／48 与 64 子带 QMF 的独立比较

日期：2026-10-17；生产起点 `8074a1c`。本轮保持生产 DSP、API、CLI、二进制和 PCM 基线不变。
机器记录见 [`qmf_width_comparison.json`](experiments/qmf_width_comparison.json)。

## 结论

统一已经验证的相位和尺度表示后，不同宽度 QMF 的差异可以分成两部分：

1. **子带包络的时间中心不同。** 8 带相对 64 带偏移 3.5 个 48 kHz 样本，48 带偏移 1/6 个。
   相位差取决于输入频率离子带中心有多远，因此不能由每个子带的另一个固定旋转完全消除。
2. **采样后的原型窗有不同的幅度响应。** 8 带窗等于 64 带窗每八项取一项；48 带窗与按左端点
   线性取样的 64 带窗最多差 1 ULP。时间中心解释大部分复数误差，幅度响应的细差仍可测量。

这不是直接改变生产 QMF 的依据。现有生产保持规范的 64 带路径；参考使用较短 IMDCT 与较窄
QMF，是另一种内部实现。其效率、逼近误差与规范裁决应分别评价，不能仅因参考输出不同就照搬。

## 固定材料与边界

复用此前已通过完整门禁的三组区间，每组两个独立参考进程：强纯音 AU 7–8、独立音乐
AU 99–100、同一音乐 AU 32–33。本轮没有重新启动参考进程，也没有把此前失败的捕获计入。
输入、窗和旋转表继续逐位核对，完整参考 PCM 摘要及捕获依据沿用
[ASF／IMDCT 记录](ASF_IMDCT_BOUNDARY_INVESTIGATION.md)和
[分析器记录](QMF_ANALYSIS_BOUNDARY_INVESTIGATION.md)。

共有 30 个分析上下文，其中 22 个非零；比较全部共同可观察子带及两个完整 AU，共 168,960 个
实／虚分量。8 个零上下文保留完整性检查，但不算相位证据。27 次 A-SPX 低带交接继续逐位
一致；HF 源带另按当前配置和生产 `PatchTable` 推导，核对捕获的频带边界。

本地使用当前 release 库的生产 `qmf::analyse`，共 90 次重放。输入从首 AU 开始，保留完整
历史和一个后置保护 AU；诊断插值不会借用环绕到文件开头的数据。三个重放模式共 17,694,720
个分量与独立数学模型比较，为 145.65–149.63 dB SNR。帧、声道与 P14 输入置换均固定。

尺度继续沿用先前边界：

```text
参考物理输入模型 = 生产 Core PCM * 2^-17
Q64 的共同表示 = 生产原始 analyse 输出 * R64(k)/128
R64(k) = -exp(j*pi*(k+0.5)/128)
```

这些换算只用于内部边界。最终对象 PCM 的 `2^-16` 比较尺度没有变化。

## 时间中心差可从原型窗推导

记宽度为 N，48 kHz 基准下的采样间隔为 `s_N=64/N`，子带中心为
`f_k=375*(k+0.5)` Hz。已验证的输入网格为：

```text
t_48k = (i+0.5)*s_N - 0.5
delta_N = (s_N-1)/2
```

QMF 原型窗却取在 `m*s_N` 的位置。去掉多相折叠引入的交替符号后，三种宽度的实原型在
`5N` 处精确对称，首项为零。因此，在理想调制的共同表示下，频率响应满足：

```text
H_N(k,f) / H_64(k,f)
  = exp(-j*2*pi*(f-f_k)*delta_N/48000) * G_N(f-f_k)/G_64(f-f_k)
```

`G` 是居中实原型的归一化余弦响应；保留它，不把剩余幅度差强行归一化。该式在分母非零处
使用，幅度响应变号时仍需保留其符号。这里两边已在共同表示中，不能再对 N 带重复乘 `C_N`。

| 宽度 | 时间中心差，48 kHz 样本 | 时间差 | 偏离中心 +187.5 Hz 时的理想相位差 |
| --- | ---: | ---: | ---: |
| 8 | 3.5 | 72.917 μs | −4.921875° |
| 48 | 1/6 | 3.472 μs | −0.234375° |
| 64 | 0 | 0 | 0° |

每个可观察子带固定核对五个频率偏移：−187.5、−93.75、0、93.75、187.5 Hz，共 280 对。
理想窗模型的剩余相位小于 `2.31e-14 rad`。从参考单位脉冲测得的算子，8 带剩余相位最多
`1.78e-8 rad`，48 带为 `5.94e-6 rad`，后者与此前旋转表的微小偏差相符。
这些位置的幅度比范围分别为 0.99998262–1.00001271、0.99995507–0.99999952。
这些通带数字不替代全子带评分，也不消除停止带的差异。

## 用单位脉冲直接验证参考算子

复用既有 56 个单位脉冲位置，覆盖 8／48 带每个输入样本位置。脉冲发生于第 2 时隙，之前
和完整滤波尾部之后的结果为零；用确定的样本位置重建 10N×N 的复数 FIR 算子。
两次参考进程的脉冲结果逐位重复，得到 47,360 个有效实／虚系数。

这是逐个输入基向量的测量，没有对音乐输出拟合增益或相位。将该算子施加到捕获的真实 PCM
和九块逻辑历史后，8 带为 140.96–141.01 dB、48 带为 138.20–139.26 dB SNR；有限精度
运算没有被写成严格逐位线性。

此前公共三音波形的较低 SNR 也获得了独立解释。下表是居中采样的全部可用子带、预热后完整
64 时隙；此外保留六个左端点网格对照和四个 64 带控制，总共 16 例。

| 宽度 | 统一表示后直接比较 | 只加入推导的频率相关相位 | 使用测得算子预测 |
| --- | ---: | ---: | ---: |
| 8 | 25.00–27.26 dB | 85.07–91.72 dB | 139.88–140.65 dB |
| 48 | 47.76–53.70 dB | 84.45–91.22 dB | 137.88–142.08 dB |
| 64 控制 | 138.53–139.13 dB | 相同 | 相同 |

时间中心来自窗和采样位置，幅度响应来自独立脉冲，不由这组波形的评分选择参数。

## 真实数据分成四个可复现的对照

所有列都与同一份实时参考 QMF 比较，输出仍停在 A-SPX 之前：

| 名称 | 输入及算子 |
| --- | --- |
| D：64 带基准 | 正式 Core PCM，固定整数延迟，生产 64 带分析，转换到共同表示 |
| C：时间中心对齐 | 对 D 的 PCM 延迟 `delta_N`，分析后乘 `exp(+j*2*pi*f_k*delta_N/48000)` |
| B：同源窄带算子 | 对同一 48 kHz PCM 在固定居中网格取样，再使用测得的 N 带算子 |
| E：较短 IMDCT | 同一本地频谱，经已验证的较短 IMDCT／窗模型，再使用相同的 N 带算子 |

诊断插值使用固定 Kaiser β=12、513 抽头 sinc，并以 1025 抽头复核；系数按解析式产生，DC
归一化与输入内容无关。插值计算显式使用 Float64，交给生产分析器前取 Float32。它需要前后
样本，只是本实验的对照方法，没有作为实时解码方案加入产品。
B 在新网格取样前保留 48 kHz 插值信号的带宽，不另加窄带低通；前端带宽与窗口效果留在
B／E 的单独比较中。两种插值长度的真实源带收敛结果也保留，避免把有限插值误差算作原语差异。

| 真实入口 | D：64 带基准 | C：时间中心对齐 | E：较短 IMDCT + 测得算子 |
| --- | ---: | ---: | ---: |
| LFE，8 带 | 22.33–25.55 dB | 83.49–85.34 dB | 137.41–138.01 dB |
| 主声道，48 带 | 50.40–57.02 dB | 82.98–94.19 dB | 117.73–125.27 dB |

B 的主声道范围为 80.73–119.29 dB：对完整 PCM 做带限插值，并不严格等同于直接用较短
IMDCT 计算新的采样点及窗口。这在强纯音尤其明显；不能把已有 ASF 网格关系误读成任意
重采样都应逐位等价。E 的残差还包含此前独立量化过的频谱和 IMDCT／FFT 数值差异。

## HF 源带单独计分

当前实际 patch 的目标边界为 `[36,44,62]`，对应源起点 `[28,18]`；另一种为
`[36,44,56]` 与 `[28,24]`。子带号按零基计数。
比较对应源带的并集，分别为 18–35 或 24–35。使用整个当前 A-SPX 低带区间的 38 时隙，
共 28,728 个实／虚分量；没有按能量挑选声道或时隙。

| 材料 | D：64 带基准 | C：时间中心对齐 | B：同源窄带算子 | E：较短 IMDCT + 测得算子 |
| --- | ---: | ---: | ---: | ---: |
| 强纯音，非零源带 | 53.95–57.07 dB | 89.69–92.55 dB | 83.80–85.92 dB | 122.93–127.10 dB |
| 音乐 AU 100 | 50.92–51.49 dB | 64.20–74.92 dB | 84.68–102.11 dB | 96.89–110.31 dB |
| 音乐 AU 33 | 51.04–52.09 dB | 85.11–88.16 dB | 106.41–115.15 dB | 119.14–126.76 dB |

AU 100 的全带 C 对照约 93–94 dB，不能代替弱 HF 源带的 64–75 dB。这里的剩余幅度响应和
泄漏差异具有更大的相对权重。机器记录同时保留源带功率误差、总功率偏差、绝对／相对误差
和 ULP，未用近零阈值隐藏数值。

纯音的 B 比 C 差，表明误差有相互抵消。固定参考 A 后，逐样本按下式记账：

```text
D-A = (D-C) + (C-B) + (B-E) + (E-A)
```

差向量闭合至约 `3.39e-21` 的绝对误差，只是核对记账；各分量的能量或 SNR 不可直接相加。
增大插值长度后，C 的 QMF 结果彼此为 142.30–150.19 dB SNR；B 在 HF 源带的收敛为
107.37–139.03 dB，明显高于对应的主要残差，但仍保留为有限插值的误差边界。
本轮没有把这些源带结果外推成完整 TNA、增益／组装或对象 PCM 的修复收益。
