# 固定 QMF 输入的 HF／TNA／预平坦化对照

日期：2026-10-17；生产起点 `a46026b`。本轮只增加测试入口、离线检查器和调查记录，生产
DSP、公共 API、CLI、默认策略和三份 PCM 基线不变。机器摘要见
[`aspx_hf_tna_comparison.json`](experiments/aspx_hf_tna_comparison.json)。

## 结论与适用范围

固定实际低带 QMF、四个时隙的历史、chirp 状态和 patch 后，**预平坦化解释了这批真实输入中
HF 生成阶段的大部分差异**。关闭本地预平坦化，两个音乐区间的逐调用比较达到
140.70–145.08 dB SNR；保留生产预平坦化时为 1.02–21.68 dB。两次非零纯音调用在关闭后
逐位一致，但其 chirp 为零，不能据此宣称纯音上的 TNA 也完全一致。

参考 HF 入口切换 preflat 标志，在 27 次真实调用及 102 个构造案例中均没有改变输出。
大幅度、上升／下降谱探针排除了“只因原生 QMF 很小，`+1` 地板把增益压到 1”的解释。
结论限定于已测参考入口和配置；不外推到所有 Dolby 解码模式。

TNA 的协方差稳定化另有分歧：真实音乐的系数差很小，近奇异矩阵、极小输入和钳位边界则
能产生明显不同。它与预平坦化问题分开，不据此删除本地 P87 的正则化。

这些指标都在**包络估计和增益调整之前**。下游可以补偿部分 HF 幅度变化，且 QMF 基底、
滤波宽度及音调初相仍有独立差异。本轮没有新的对象 PCM A/B，不将上述数字写成最终修复收益。

## 检查点与独立重放

复用[ASF／IMDCT 对照](ASF_IMDCT_BOUNDARY_INVESTIGATION.md)已通过完整门禁的检查点：
强纯音 AU 8、音乐 AU 100、音乐 AU 33，每份各 9 次 HF 调用，共 27 次。调用号不是最终
21 路对象 PCM 的路号。之前两次独立捕获的低带及有效历史逐位一致。

本轮另启动四个独立参考进程：纯音完整 143 AU 两次，音乐完整 400 AU 两次。每次先完成
全段 PCM 导出，再把同一组固定输入、配置和历史的自有副本送入参考原语。没有新增实时 DSP
挂钩；配置保留捕获的标量字段，清除原生不透明指针。专有入口适配、版本／签名验证和原始
工作区继续只在本地保存。

四次最终运行均满足全部 AU 成功、参数设置成功、每 AU 的 2048 × 21 个 Float32 样本完整且
有限、整段 PCM SHA-256 等于未插桩基准。129 个 HF、112 个 chirp 和 18 个解算器案例的
全部结果在四个进程中逐位相同。27 个真实 HF 输出也逐位复现既有捕获的生成区域。

参考自有实例的结束低带历史、chirp 和模式状态已检查，并与本地推进结果比较；有效历史仅取
`sb < sbx`。原生历史缓冲的后缀可能含本次写入的 HF，不能拿它当作下一次预测使用的低带。
这不是新增的实时嵌套 TNA 结束挂钩，不能扩大为此前所有内部状态均已直接捕获。

探索阶段一份旧版适配器运行返回 `-5`，虽然已返回 143 AU，仍未通过完整门禁，已排除并保留
日志。最终四份运行均首次通过。不把探索失败解释为参考拒绝码流。

## 表示、输入与检查器

两边 HF 算子使用相同的参考 QMF 基底，固定以下已验证的接口尺度：

```text
本地生产幅度单位下的固定输入 = 捕获低带 QMF × 2^23
本地 HF 输出比较值 = 本地 HF 结果 / 2^23
参考 HF 输出比较值 = 原生 HF 结果 × 4
```

`2^23` 来自此前 Core／QMF 边界的尺度，不由这次输出拟合。原生 HF 的 `1/4` 接口因子已在
[基底算子调查](ASPX_BASIS_OPERATOR_INVESTIGATION.md)验证。这里不额外乘逆 R，也不改变
跨子带算子的定义；这是固定同一表示下的局部实验。最终对象 PCM 的 `2^-16` 尺度不变。

另跑一份 `raw` 单位输入，用于区分幅度尺度与 `+1` 地板。无预平坦化的预测系数和 HF 输出
在这两种二次幂尺度下逐位一致；`raw` 预平坦化不能冒充生产行为。

测试入口位于 [`tna/replay_tests.rs`](../crates/macindecode-ac4-decode/src/aspx/tna/replay_tests.rs)，
直接调用现有 `prediction_filters`、`chirp_factors`、`pre_flatten`、`hf_generate` 和历史推进，
不复制一套生产实现。频带、噪声组和 patch 均经现有推导核对；只知道 `sbx` 时要求交叉偏移
解唯一，不以相同尺寸代替来源证明。

[`check_aspx_hf_replay.py`](../scripts/check_aspx_hf_replay.py)检查完整案例集合、参数、固定形状、
有限值、参考结束记录、两次幂尺度不变量和有效结束状态。构造输入按公开配方重建核对；
协方差另按时间步长及共轭定义计算，预平坦化增益另用最小二乘求解验证。两套幅度表示下的
4,644 个增益各与独立模型逐位一致。未拟合参考输出的增益、相位或延迟。

归一化夹具协议为 `macinac4.normalized-hf-replay` v1。参数是自有的 176 字节小端格式
`<33I4x2Q5f4x`：16 个几何字段、6 个噪声边界、6 个目标边界、5 个源起点、当前／前一模式
各一个 `u64` 和 5 个前一 chirp。它不含指针，也不是原生内存结构。输入 QMF 存储
`[40,64,2]`，前 38 行有效；历史为 `[4,40,2]`；最后一维为实／虚分量。清单声明各字段与
案例顺序。原生配置副本不进入该公开归一化数据协议。

在已核验挂载身份的外置实验目录中，可用以下入口重放；输出目录必须是新的：

```sh
MACINAC4_HF_REPLAY_DATA="$EXPERIMENT/normalized_inputs" \
MACINAC4_HF_REPLAY_NATIVE="$EXPERIMENT/references/r0" \
MACINAC4_HF_REPLAY_OUTPUT="$EXPERIMENT/new_local_output" \
cargo test -p macindecode-ac4-decode --features audio-decode \
  replay_fixed_hf_inputs -- --ignored --nocapture

python3 scripts/check_aspx_hf_replay.py "$EXPERIMENT/manifest.json" \
  "$EXPERIMENT/normalized_inputs" "$EXPERIMENT/references" \
  "$EXPERIMENT/new_local_output" --output "$EXPERIMENT/new_comparison.json"
```

## 真实 HF 比较

每项保留该区间全部调用、完整生成区间及全部目标子带，不筛选高能量分量。表中是逐调用
SNR 范围；合计误差能量、绝对／相对误差和 ULP 另见机器摘要。零参考分量不参与最大相对
误差的分母，仍计入绝对误差、总能量和逐位比较。

| 输入 | 非零调用／全部 | 生产预平坦化 | 关闭预平坦化 | 关闭且固定参考 alpha／chirp |
| --- | ---: | ---: | ---: | ---: |
| 纯音 AU 8 | 2/9 | −7.90、54.95 dB | 逐位一致 | 逐位一致 |
| 音乐 AU 100 | 9/9 | 8.91–15.23 dB | 140.70–144.53 dB | 145.70–147.48 dB |
| 音乐 AU 33 | 9/9 | 1.02–21.68 dB | 141.79–145.08 dB | 144.91–147.71 dB |

最后一列把实际测得的系数和 chirp 送入同一生产 `hf_generate`，仅隔离乘加数值差；不是对
输出拟合新系数，也不是可用于正常解码的候选实现。

关闭预平坦化后，594 个逐子带结果中，有有限 SNR 的范围为 **133.77–152.89 dB**，零及逐位
一致的结果也完整保留。两份音乐的最大绝对分量误差分别为 `2.33e-10`、`2.91e-10`，最大
相对误差为 `1.29e-4`、`1.97e-4`，最大 ULP 为 1,088、2,537。相对／ULP 极值会被接近零的
分量放大，不能据它否认总误差已很小，也不能只报总 SNR 隐去这些极值。

## 预平坦化：原生入口无效与字面方向冲突是两件事

48 个专门探针使用平坦、上升、下降和交替高低谱，幅度因子为
`2^-50, 2^-30, 2^-10, 1, 2^10, 2^20`，区间为 `[0,32)` 与 `[2,38)`。固定 chirp 为零，
避免把 TNA 残差当成预平坦化。加上真实及 TNA 输入，129 个案例中有 116 个非零；所有案例
切换参考 preflat 标志均逐位相同，零 chirp 时还逐位等于固定 patch 的源样本乘 `1/4`。

大幅度有斜率的输入上，字面 P85 已会产生远离 1 的增益，参考标志仍无影响。因此此前仅靠
原生幅度很小、`+1` 或舍入来解释参考行为的假设不够。在已测入口上，观测行为等价于旁路
预平坦化；这个观察本身不裁决规范。

`TS103190-1:v1.4.1:5.7.6.4.1.2` 的 P85 与 `5.7.6.4.1.4` 的 P89 另有此前已经登记的
方向冲突：`g=10^((mean-slope)/20)` 再除以 `g`，会扩大谱斜率。本轮把这个数学判断接到
实际生产原语：16 个高能量上升／下降案例的输出 dB 斜率为输入的
**1.999993–2.000000 倍**，参考为 1 倍。只作数学对照的乘法方向将斜率压到
`1.41e-5 dB/子带` 以内。

该矛盾在 2026-10-01 已记录，本轮是独立实证，不是再次发现。乘法可以满足平坦化方向，
旁路可以吻合已测参考入口，两者并非同一个决策。生产仍保留现有 P85/P89，尚未改为任一候选。

## TNA：协方差稳定化与阈值单独辨别

先核对 P86：扩展输入为 4 个历史和 38 个当前时隙，求和时间索引为
`4,6,...,40`，每级预测跨 2 个 QMF 时隙。独立双精度协方差与生产计算一致。参考还对
协方差做共同二次幂放大：当最大绝对项为 A 且非零时，观测指数为
`max(0,min(60,-1-floor(log2(A))))`；不会向下缩小大输入。在未触及上限时，小协方差的
最大归一化项落在 `[0.5,1)`。

独立改变输入二次幂幅度，避开参考的放大区，再按这个规则还原，129 个案例有效源子带的
前八个协方差分量均逐位复现。指数由输入协方差及该独立控制决定，不通过拟合输出 alpha 消差。

生产 P87 的分母保留：

```text
D_local = c11*c22 - |c12|^2/(1 + 2^-20)
```

已测参考协方差／解算器的对应分母未见这一相对正则项，而在归一化后的 `abs(D)` 和 `c11`
使用 `2^-31` 的绝对门槛。18 个直接协方差控制覆盖退化程度、系数模长 4、分母和对角项
阈值的下方／等于／上方以及全零输入：

| 固定输入控制 | 参考观察 | 生产观察 |
| --- | --- | --- |
| 高相关协方差，相关系数 `1-2^-20` | alpha1 实部约 0.250000 | 约 0.166667，正则化改变解 |
| 分母刚低于 `2^-31` | alpha1 为 0 | 构造案例为 0.5 |
| 对角项刚低于 `2^-31` | alpha0 为 0 | 构造案例为 0.5 |
| 相同阈值的等于／上方 | 对应分量为 0.5 | 对应分量为 0.5 |
| Float32 表示的 `±2.4+3.2j` 边界 | 保留系数 | 触发不稳定清零 |

最后一项同时涉及精度和边界比较，不能仅凭输出把它定性为规范错误。54 个完整 TNA 探针又
覆盖全零、随机、单音、双音、四档近单音与脉冲，分别跑六档幅度。随机输入除最小幅度外
约 142.26 dB SNR；近奇异与单音可以降到个位数 dB。极小输入还触及参考归一化上限与
绝对门槛，本地的相对正则化则保持尺度不变。

这些构造分歧确实存在，但真实音乐的 alpha 最大绝对差只有约 `3.28e-7`／`2.98e-7`，
不足以解释前述预平坦化量级的 HF 差异。生产正则化有其数值稳定目的，参考吻合不构成删除它
的理由；本轮未调整 TNA 策略。

## Chirp、验证和后续

112 个 chirp 控制遍历当前／前一模式的 4×4 组合，以及 7 个历史值，包含 `1/16` 的邻值。
104 个结果逐位相同，其余最多 1 ULP，最大绝对差 `5.96e-8`；零／非零判断全部一致。
真实 27 次调用的 chirp 数值均逐位相同，结束模式与历史检查也通过。

默认工作区测试 516 项、音频测试 1303 项、相关 Python 测试 109 项通过；默认和音频 Clippy
均通过 `-D warnings`，rustfmt、层审计和 diff 检查通过。新增 17 项 Python 检查已接入 CI。
原有 190 份 Rust 文件中，189 份摘要不变，另一份仅增加 `#[cfg(test)]` 模块声明；release
二进制、用户 `gen_damf.py` 和三份基线摘要不变。本轮未重建 release 或重导出 36 条 PCM 基线。
所有新增大文件写入核验过身份的 cache 卷，构建仍复用原 `target`。

下一处应固定本轮 HF 输出，继续比较**包络估计 → 调整增益 → 组装**，量化预平坦化的幅度变化
被抵消了多少、哪些形状和边界会传播到输出。完成后再分别决定预平坦化方向／旁路策略与
QMF 基底／音调初相；不把参考原语的稳定化习惯直接升级成生产规范。

同日后续的[包络／增益／组装调查](ASPX_DOWNSTREAM_INVESTIGATION.md)已完成这一步的
固定输入对照，并另行识别了 onset 噪声条件分歧；生产策略仍未调整。
