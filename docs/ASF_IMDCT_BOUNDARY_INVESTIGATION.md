# ASF／IMDCT 到 QMF 输入的独立对照

日期：2026-10-17；生产起点 `e61e9d8`，DRP 4.3.0.19350 arm64。
本轮只增加离线检查器、测试和记录，生产 DSP、二进制、API、CLI 与 PCM 基线不变。
机器摘要见 [`asf_imdct_boundary_comparison.json`](experiments/asf_imdct_boundary_comparison.json)。

## 已确认的边界

此前[分析器调查](QMF_ANALYSIS_BOUNDARY_INVESTIGATION.md)留下的主要缺口，是本地 48 kHz
PCM 与参考内部 6／36 kHz PCM 的来源和时间轴。本轮已经追到实际 ASF 频谱及 IMDCT：

- 参考在主声道上使用较短变换：本地 2048／1024／512 点块分别对应 1536／768／384 点；
  LFE 的 2048 点块对应 256 点。它们仍跨越相同的物理时间，不能直接按样本下标相减。
- 按码流规定的 A-JOC 输入置换和块长尺度比较，真实频谱的整体 SNR 为 **145.76–146.60 dB**。
  没有逐声道搜索相关性、重新排列或拟合输出增益。被较短变换舍弃的本地高位谱线全为零。
- 82 次真实变换的独立参考重放逐位复现输出和结束工作区；其中 66 次输入非零。
  短块、长短块切换和跨帧历史均有覆盖。
- 从本地频谱重建参考尺寸的 PCM，按固定采样位置、窗和延迟送到分析器入口，主声道为
  **120.41–125.53 dB SNR**，非零 LFE 为 **140.32–140.42 dB SNR**。
  这使用捕获的实际窗；只用本地窗的居中线性取样模型，主声道也为 120.38–125.37 dB。

这些结果说明，在已测材料上，大幅末端差异没有出现在 ASF 频谱或 IMDCT 时间轴这一段。
仍有可测量的数值残差，尤其是参考 FFT；本轮没有据此改变生产算法或裁定参考实现是否符合规范。

## 捕获、来源与状态

| 材料 | 完整 AU | 观察 AU | 变换数 | 非零变换 | 实际 N |
| --- | ---: | --- | ---: | ---: | --- |
| 强纯音 | 143 | 7–8 | 20 | 4 | 256、1536 |
| 独立音乐 | 400 | 99–100 | 29 | 29 | 256、768、1536 |
| 同一音乐的另一段 | 400 | 32–33 | 33 | 33 | 256、384、768、1536 |

每个区间采用两个独立进程的完整成功捕获。参数设置成功，所有 AU 返回成功，输出样本有限，
整段 PCM 摘要与未插桩参考相同；既有 QMF、HF、逐包络增益／组装检查仍通过。纯音和音乐
所用适配器版本分别记录：后一个版本只在离线 IMDCT 重放时增加无效工作区清零对照。

参考内部全频带槽按 A-JOC 输入顺序对应本地 `ajoc_input_order()`，LFE 单独对应。九路
fullband 的置换由 P2 `5.7.2.1` P14 固定，不由波形决定。参考 ASF 输出缓冲与每个分析器的
PCM 输入缓冲使用相同分配身份；每 AU 的 32 次调用又逐项验证连续的 8／48 样本步幅。
这是内部来源关系，不把内部槽号当成最终 21 路对象 PCM 的路号。

本地提取器直接调用已有频谱重建函数和 `FullAjocDecoder` 前端，复用现有 release 依赖。
它导出的完整纯音／音乐 Core PCM 共 **11,120,640 个样本**，与当前正式 CLI 出口逐位一致。
没有另建 Cargo 缓存，也没有给产品增加诊断参数。

每次原语记录输入频谱、前旋转、FFT、后旋转、重叠工作区及返回后的结果。复制真实输入与
状态进行独立重放，覆盖 84,480 个变换结果值和 87,936 个结束工作区值。前置历史的有效范围
共 45,696 个值，两次进程捕获逐位一致。

**工作区后缀不等于有效历史。** 原始快照有少量未使用位置保留了进程相关数据。规范化工具
只保留按块长与上一块长度确定的有效前缀；音乐的全部 62 次变换另把无效后缀清零后重放，
结果与结束工作区依然逐位一致。纯音 20 次采用原始工作区重放，不能记作新的清零对照通过。
检查器在每块摘要中分别报告这两种验证范围。

另有超时、SIGTRAP，以及一次完成解码但 PCM 摘要不符的尝试，均被门禁排除。进一步尝试
取得纯音清零对照的完整捕获仍失败，此项保留为未闭合；不把失败解释为码流拒绝，也不因
局部重放成功而接纳未完成的进程。原因尚未唯一归因，失败材料继续留在本地。

## 统一频谱尺度与采样位置

设码流的原始块长为 `M`，参考变换长度为 `N = M*width/64`。捕获支持的输入约定是：

```text
X_reference[k] = X_local[k] / (M * 65536)
D_N[j] = sum_k X_reference[k] * cos(pi/N * (j+0.5)*(k+0.5))
```

参考原语的余弦变换未归一化；其 `1/M` 已进入频谱尺度。这个分母是原始块长 **M**，
不能换成较短变换长度 N，也不能对所有短块继续固定使用 2048。

零填充的完整 IMDCT 与较短 IMDCT 的无窗部分，在以下物理采样位置有同一个余弦定义式：

```text
t_48k = (i + 0.5) * 64 / width - 0.5
```

工具用独立的密集余弦矩阵检验这条关系；没有通过移动 PCM 找最佳延迟。实际分析输入的
额外延迟为表 188 的 **352 个 48 kHz 样本**，对应主声道 264、LFE 44 个内部样本，亦与
参考合成端实际保留的前缀长度一致。此前分析输出到 A-SPX 的 6 个 QMF 时隙属于另一边界。

生产 Core PCM 采用 `2/M`，因此本轮 64 宽控制与 Core PCM 的固定比较尺度为 `2^-17`。
控制使用生产窗和完整频谱、预热全部早先 AU，得到 142.95–144.91 dB SNR。这只验证本次
内部模型的尺度和历史；**最终对象 PCM 的既有 `2^-16` 比较尺度未改**。

## 把变换内部的残差分开

相同余弦定义式也可独立分解成 N/2 点复数 FFT：

```text
z[k] = 0.5 * (X[2k] + j*X[N-1-2k]) * exp(-j*pi*(k+0.25)/N)
F = FFT(z)
v[k] = F[k] * exp(-j*pi*k/N)
D[2k] = 2*real(v[k])
D[N-1-2k] = -2*imag(v[k])
```

检查器每一步都使用该步捕获的真实输入，比较结果取 Float32 后计分：

| 参考变换长度 N | 前旋转，逐块 SNR | FFT，逐块 SNR | 后旋转，逐块 SNR |
| --- | ---: | ---: | ---: |
| 256 | 150.71–188.43 dB | 142.25–143.55 dB | 146.33–148.67 dB |
| 384 | 146.04–149.57 dB | 124.18–124.77 dB | 146.62–148.38 dB |
| 768 | 144.09–163.26 dB | 123.37–126.64 dB | 146.16–148.88 dB |
| 1536 | 145.34–158.30 dB | 122.06–124.48 dB | 146.44–148.41 dB |

主要数值差异已定位到非二次幂变换中的 FFT 步骤；这里的 N/2 分别是 192、384、768。
没有继续把它唯一归因到某个近似常量、某一次舍入或整条编解码策略，也没有把各行 SNR 相加。
ULP 和相对误差在接近零的参考值处可以较大，机器记录保留它们及绝对误差，未用阈值隐藏。

公式固定后，用零输入、首／末谱线脉冲及两份固定种子随机谱再确认。三组捕获各有这些控制，
共 45 个调用、36,480 个结果值；去重后是 **20 种配置，其中 16 种非零**。它们不是 45 种
独立尺寸覆盖。两次进程的输入与输出逐位重复，余弦模型为 122.94–149.36 dB SNR。

## 窗与真实 PCM 交接

较短窗与本地原始 KBD 窗在上述居中坐标上的线性取样非常接近：本轮使用的全部配置最大
绝对差约 `4.17e-7`、最大 7 ULP。这支持当前诊断模型，但尚不能唯一证明参考表的生成规则。
实际捕获窗作为另一组明确的参数输入，独立比较，不从 PCM 输出反推补偿系数。

每个物理源从首 AU 的零历史开始，按实际块序列执行 IMDCT、窗口和重叠相加，再施加固定
延迟，评分覆盖两个目标 AU 的全部样本；没有丢弃短块边界或难以拟合的声道。

| 分析入口 | 本地窗的居中线性取样 | 捕获的实际窗 | 非零上下文 |
| --- | ---: | ---: | ---: |
| 8 带／6 kHz | 129.01–129.35 dB | 140.32–140.42 dB | 2/3 |
| 48 带／36 kHz | 120.38–125.37 dB | 120.41–125.53 dB | 20/27 |

其余八个上下文为零，仍参与完整性核对，但不算相位或幅度证据。采用实际窗后，主声道残差
仍与变换内部的数值量级相近；不是把一个未知的整体误差用自由增益抵消了。

## 验证与下一处边界

新增 [`check_asf_imdct_checkpoints.py`](../scripts/check_asf_imdct_checkpoints.py)，检查完整声道
所有权、P14 置换、每块长度和偏移、跨帧块长、有效历史、重复捕获、原生重放、探针配方与
有限值。它拒绝缩短变换时舍弃非零谱线，接受结果始终标为 `observation_only`。

```bash
python3 scripts/check_asf_imdct_checkpoints.py /absolute/path/manifest.json \
  /absolute/path/normalized --output /absolute/path/new_comparison.json
python3 -m unittest scripts/test_check_asf_imdct_checkpoints.py
```

15 项新增测试、合计 76 项相关 Python 测试，以及格式、层审计和 diff 检查通过。190 份现有
Rust 源码、生产二进制、用户的 `gen_damf.py` 和三份基线摘要未变。本轮未重新导出既有 36 条
基线；另行完成了上述两份原流的正式 Core PCM 全段逐位核对。新增大文件全部放在经卷身份
检查的外置 `cache` 实验目录，地址、适配器、原始矩阵和表不进入仓库。

下一步应以这组真实 ASF 输入为固定基准，继续比较 **8／48 与 64 子带 QMF 在同一物理
信号上的作用**，并追踪差异怎样进入 HF 源子带。此前解析公共波形的低 SNR 不能再归因于
未知的 ASF 采样位置，但较短变换可解释并不意味着两种 QMF 已经等价。参考 FFT 的细小残差
可单独保留；生产基底、音调初相与预平坦化仍各自需要证据和决策。

同日后续的 [QMF 宽度比较](QMF_WIDTH_INVESTIGATION.md)已分离包络时间中心与原型响应差异，
并以测得的窄带算子检验真实输入。完整 PCM 的带限插值与直接较短 IMDCT 仍有可观察差别，
与本报告的无窗采样坐标关系并不矛盾；这两种前端实现被作为单独对照保留。
