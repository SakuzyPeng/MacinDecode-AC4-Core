# TNA 数值稳定性：独立 QR 与清零边界反例

日期：2026-10-18。起点：`b9838f4`。状态：**以下保留修复前的独立调查；后续已按 ADR-0023 应用数值修复**。
机器摘要见[实验记录](experiments/aspx_tna_stability_comparison.json)。

修复实现及单独验证见 [ADR-0023](decisions/0023-stabilize-aspx-prediction-with-orthogonal-residuals.md)
与[修复机器记录](experiments/aspx_tna_stability_fix.json)。本页的旧生产数值和宿主候选结果
不追溯改写。

本轮没有采用 DRP 的稳定化规则。现有正则项在实际输入上的解符合独立最小二乘目标，
但一个刻意靠近模长 4 的构造案例中，协方差累加误差使本应清零的系数被保留。
378 个真实源子带窗口没有发生该误判，不能把它解释为当前完整 PCM 差异的主因。

## 固定的数学目标

保持 `TS103190-1:v1.4.1:5.7.6.4.1.3` / P86/P87、ADR-0017 的交叉项减号及
`5.7.6.4.1.4` / P89 的滤波连接。重新目视核对印刷页 219：任一预测系数模长
**大于或等于 4** 时，两者一起置零。

令 P86 的三个抽头为 `y=x[t]`、`x1=x[t−2]`、`x2=x[t−4]`，采样位置从 4 起每次加 2。
第一延迟列非零时，现有正则化等价于：

```text
min ||y + a0*x1 + a1*x2||² + lambda*|a1|²
lambda = |<x1,x2>|² / (||x1||² * 1048577)
```

其中 `<u,v>=sum(conj(u)*v)`。lambda 非负，第一条正规方程不变；它不是要求无正则
预测残差最小的同一个问题。因此，不能以参考的无正则解更接近某个输出为由删除它。

独立 oracle 把第二抽头的惩罚写成增广矩阵的一行，再用 **100 位 Decimal 两列 QR**
求解，不形成生产的行列式或复写浮点闭式。输入始终是实际送入 Rust 的 f32 位型。
零列和全静音另作定义，不凭空给退化矩阵加一个参考绝对阈值。

严格清零边界使用 `Fraction` 对 f32 输入的精确有理数正规方程裁决，并与 QR 交叉核对。
首轮有限精度 QR 曾把 17 个数学上恰好等于 4 的案例报成略低于 4；差距只有约 `1e−93`。
这些是 oracle 的末位舍入，已排除，不能算生产缺陷。提高精度本身不代替严格等号证明。

## 输入、出口和覆盖

| 输入 | 数量 | 覆盖 |
|---|---:|---|
| 合成谱序列 | 1,216 | 19 种形状 × 表 189/192 的 8 档几何 × 8 档幅度 |
| 近模长 4 的复数增长序列 | 256 | 固定倍率、不同相位；专门检查清零分支 |
| 已捕获的真实有效源带 | 378 | 纯音、音乐 AU 100、音乐 AU 33，各 9 次调用的完整 patch 源带并集 |
| 合计 | **1,850** | 全部有限输入均成功返回有限系数 |

形状包括零、常量、单音、双音、六档近单音、随机、复数斜坡、首尾脉冲、增长／衰减
及模长 4 上下邻域。幅度指数为 `−149, −130, −100, −50, 0, 50, 100, 125`。
极端 f32 只是接口数值压力测试，不代表这些量级和增长速度已在合法编码媒体中出现。

真实数据复用[HF／TNA 调查](ASPX_HF_TNA_INVESTIGATION.md)的固定低带及四行历史，沿用
`×2^23` 的生产幅度换算；本轮不启动参考进程。纯音每调用 18 个不同源带、两组音乐每
调用 12 个不同源带，不把重复 patch 来源当作独立子带。

测试入口实际调用 covariance、solve、prediction_filters，分别记录协方差、清零前
f64 解和实际 f32 存储值。另以实际存储系数驱动 hf_generate，关闭预平坦化，分别取
chirp `0 / 0.6 / 0.9 / 0.98 / 1`。为避免故意的大幅度压力输入使 f32 输出加法溢出，
HF 输入按预先声明的二次幂归一化；这只检验给定系数的消费，不冒充原幅度端到端解码。
HF 使用 `0→36` 的单带原语路由，不声称该隔离路由由 P71 的合法码流配置推导而来；
TNA 的每个源子带解算使用同一算法，实际 patch 几何仍由既有推导与连续链测试负责。

949 个合成案例的缩放在 f32 上仍精确，152 个信号／几何组的系数逐位保持；其余
267 个合成案例发生输入量化或归零，按改变后的实际位型重新求解，不要求它们与原输入
产生相同系数。清单和检查器都核对这一分类，不能借改标签隐藏缩放不一致。

## 原始解的数值误差

用列范数和目标范数归一化系数误差，避免把大小不同的预测列混比。门槛根据 f64 epsilon、
求和项数及 `2^-20` 的正则强度事先确定；全部原始解在该保守前向界内，最坏占界的
`0.001998`。这只证明连续数值误差小，**不意味着硬阈值分类必然正确**。

| 输入 | 最大原始复系数绝对误差 | 最大加权误差 | 生产清零案例 |
|---|---:|---:|---:|
| 普通合成序列 | `6.565e−9` | `4.928e−10` | 104 |
| 近阈值相位扫描 | `6.186e−9` | `3.867e−10` | 143 |
| 真实有效源带 | `1.410e−15` | `1.407e−15` | 0 |

给定实际存储系数的 9,250 份 HF 输出全部符合独立复数滤波的固定前向界，最大误差占界
`0.06465`。本轮的问题出在系数选择，未发现 HF 消费或历史索引的新偏差。

另有 22 个近阈值案例在 f64 判定通过后，收窄到 f32 的模长达到或略超过 4。这与下面
“原始数学解应清零却被保留”是两件事。是否对存储后的系数重新判定会改变边界策略，
本轮没有据此追加第二次钳制。

## 确认的反例 b217

使用合法 `N=32、offset=6` 的 42 个复样本：前四个是历史，后 38 个是当前低带。
原始构造是快速增长的复数序列，相邻两个 QMF 时隙的理想增长因子模长为 4，角度为
`217π/512`。为防宿主三角函数版本改变这个敏感输入，公开检查器固定了它的 84 个
f32 分量位型。这是自有合成输入，不含许可表、媒体或参考捕获矩阵。

| 解算层次 | alpha0 的模 | 按 `>=4` 的结果 |
|---|---:|---|
| 精确 f32 输入的有理数解／独立 QR | `4.0000000007796116…` | 双系数清零 |
| 生产已经舍入的 f64 协方差，再作精确解算 | `3.9999999997861313…` | 保留 |
| 当前生产 f64 求解结果 | `3.9999999999916641…` | 保留 |

精确 `|alpha0|²−16` 为正，约 `6.236893e−9`。这排除了 QR 最后一位误判。
而第二行表明，在浮点闭式求解之前，协方差累加舍入就已经把该输入推到了另一侧；
只把后续行列式算得更准，未必能恢复正确分类。

硬阈值将很小的连续误差放大为完全不同的滤波选择：

| chirp | 当前 HF RMS / 正确清零后的 HF RMS |
|---|---:|
| 0 | 1 |
| 0.6 | 约 0.4 |
| 0.9 | 约 0.1 |
| 0.98 | 约 0.02 |
| 1，隔离用控制 | 约 `6.54e−8` |

这是固定输入、关闭预平坦化的局部 HF 比较。后续包络补偿、真实出现概率、对象 PCM 和
听感都没有由这张表确定；特别不能把 0.02 写成整段音频改善 34 dB。

## 数学等价的候选与未完成项

仅在 Python 调查中尝试先消去第一列的投影：

```text
p1 = <x1,y>/||x1||²;  p2 = <x1,x2>/||x1||²
v = y − p1*x1;        u = x2 − p2*x1
a1 = −<u,v>/(||u||² + lambda)
a0 = −p1 − a1*p2
```

它保持同一非负 ridge 目标，避免以两项接近的大协方差乘积相减来求很小的分子。
本批 1,850 例的最大加权误差从 `4.928e−10` 降至 `1.476e−14`；与精确分类的分歧
从 1 例变成 0 例。该结果支持继续做数值等价修复，**不支持去掉正则项、修改模长阈值或
改成参考绝对门槛**。

候选目前是宿主 NumPy 实验，尚未移植到生产、检查不同目标的确定性或测量运行成本。
下一步应把固定反例变成修复前失败的生产回归，验证无 FMA 的 Rust 实现、零列／极小值
和跨帧边界，再单独评估完整 PCM 及所需基线变化；不能将本轮调查称为已交付修复。

## 验证与复现

三个新增普通 Rust 判据覆盖 160 个精确幅度组合、正则化的第二条正规方程、最小非零／
最小正规／最大 f32 及后续子带失败时的事务性。实际注入去正则、协方差提前降至 f32、
把 `>=4` 改成 `>4`、绕过非有限拒绝，已有及新增 TNA 判据全部检出；两种等价改写及
恢复源码后的基线通过。

14 个新增 Python 测试覆盖 QR、精确边界、缩放与量化分类、构造覆盖和文件门禁。
