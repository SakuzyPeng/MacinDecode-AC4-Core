## 2026-09-23 结论

两项相互耦合的差异能解释本轮音乐样本的大部分 12–18 kHz 残差：

1. A-SPX 频带搬移后的相位与参考输出存在系统性差异，符合一组明确的 QMF 相位变换。
2. 噪声索引中的 `atsg_sig[0]` 按 QMF 时隙换算后，在上述相位条件下明显接近参考。

联合模型在未参与选择参数的后半段降低误差能量约 **10.50 dB**，独立 768K 音乐降低约
**8.81 dB**。这不是仅由浮点舍入造成的随机波动；也不等于模型已成为规范要求或解码已逐位一致。
生产 DSP 保持不变：当前 QMF 代码符合 Pseudocode 65/66 字面，不能仅凭更接近某个 runtime
就替换它。临时探针完成后源码恢复，正式 release 二进制与实验前逐字节相同。

## 真实帧先验

训练输入是首轮真实音乐前 400 AU，48 kHz、2048 samples/AU，9 条全带 downmix 输入。
本地诊断记录中，399 个完成重建的控制帧共调用噪声和音调工具各 3591 次：

- `sbx = 36`，A-SPX 起点 13.5 kHz；覆盖 20 个 QMF 子带，`num_ts_in_ats = 2`。
- 噪声电平每次调用均有非零项；音调电平全部为零。因此该输入不能验证音调相位。
- 噪声 `master_reset` 与音调 `first_frame` 各仅在起解时的 9 路调用为真。没有观测到反复
  初始化；本输入也没有覆盖频率配置实际变化后的复位分支。
- 区间左边界非零只有 5 次，均在控制源 AU 18，具体数值见原始实验记录。
  其中三次为 ATS 2、两次为 ATS 3；这些调用之后的游标会继续跨帧携带。
- patch 固定为 `28..36 → 36..44` 和 `24..36 → 44..56`，位移分别为 8、20 个子带。

另一个曾标成“每 I 帧复位”的诊断开关实际检测的是 effective config 是否存在。在当前驱动中
该配置每帧都可用，故它等价于每区间复位。这个变体已按实际语义记账，不能据此声称验证过
“只在真实 I 帧复位”的另一种算法。

## 相位模型及其可辨识边界

令 `omega_k = pi * (k + 0.5) / 64`。P1 `5.7.3` 的 Pseudocode 65 使用
`exp(j * omega_k * (n - 0.5))`；`5.7.4` 的 Pseudocode 66 使用
`exp(j * omega_k * (n - 127.5))`。已逐页核对原 PDF；Part 2 `4.8.3.9` 引用的也是
Part 1 的分析工具，没有在该条款另给一个替代相位公式。

诊断模型对分析输出乘：

```text
R(k) = -exp(j * omega_k / 2)
```

终端合成输入乘其逆。它等价于分析使用 `-exp(j * omega_k * n)`，合成使用
`exp(j * omega_k * n)`。这是本次所谓“零中心相位模型”，不是新增的生产模式。
旋转量先由 patch 的相位关系提出，再在训练段比较有限候选，随后固定用于验证段；没有为每个
对象或验证段单独寻找最优相位。该变体会改变生成分量相对直达分量的相位和最终 PCM，不能将它
当作比较脚本末端可无损消掉的全局延迟或幅度常量。
两段阶跃对应的是频带搬移跨度，不等于给整个 PCM 增加半个采样的延迟。

同一子带直接分析再合成时，两端变换互相抵消；A-SPX 从低带 `p` 搬到高带 `k` 时却留下：

```text
R(p) / R(k) = exp(-j * pi * (k - p) / 128)
```

因此两个 patch 应分别偏移 **-11.25°、-28.125°**。未参与调参的音乐后半段中，参考相对
本地的对应相位约为 **-11.48° / -10.98°**（第一个 patch 内两段）和 **-27.81°**；
联合模型后收敛到约 **+0.073° / +0.029° / +0.007°**。这比“可能是舍入误差”更具体，
也解释了为什么只检验 QMF 直接往返不能发现这一类跨工具相位问题。

该模型**不能唯一识别参考库的内部实现位置**。使用不带全局负号的 QMF 旋转，同时将噪声、
音调各反相，能得到逐字节相同的最终 PCM；本轮已验证这个等价变体。因此能确认的是端到端
相位约定的差异，不能仅凭黑盒输出断言“杜比内部某个函数就使用这些系数”。

## 噪声游标的单位问题

Pseudocode 102 的循环变量 `ts` 是 QMF 时隙，Pseudocode 103 却写：

```text
num_sb_aspx * (ts - atsg_sig[0])
```

`atsg_sig[0]` 的单位是 ATS。候选解释将它换算为
`atsg_sig[0] * num_ts_in_ats`。训练输入的 AU 18 因而出现两个明确分歧：

| 左边界 ATS | 原游标下一值 | 换算后的下一值 | 差额 |
| --- | ---: | ---: | ---: |
| 2 | 424 | 384 | 40 |
| 3 | 444 | 384 | 60 |

差异只有少数边界触发，却会通过 `noise_idx_prev` 影响后续大量帧。单改这一项反而恶化原始
比较；把相位约定一起纳入之后，误差才明显下降。这说明单项 A/B 在另一项失配存在时可能误导
判断，不能把“单改后变差”直接当作伪码字面已获验证。

| 固定模型 | 训练 400 AU | 未参与调参的后 400 AU | 独立 768K 音乐 |
| --- | ---: | ---: | ---: |
| 仅换算噪声起点 | -1.48 dB | -2.14 dB | -2.68 dB |
| 仅相位模型 | +4.91 dB | +2.12 dB | +0.47 dB |
| 两项联合 | **+10.61 dB** | **+10.50 dB** | **+8.81 dB** |
| 联合后再交换噪声表实虚列 | — | +0.075 dB | -0.57 dB |

正数表示固定尺度、固定延迟下的误差能量下降，负数表示恶化。没有用拟合增益计分。
另一份 1500K 对照的 `sbx = 50`，A-SPX 从 18.75 kHz 才开始；它在 12–18 kHz 的不变
不构成对此问题的正向验证。

## 表 D.2 与音调

首轮“交换实虚列使 20 路对象略有改善”不能继续作为换列的证据：改变噪声符号、偏移一个表项
甚至将噪声置零，也会改善未统一相位时的原始误差。联合模型下，交换列序显著破坏结果。
当前 `{re, im}` 顺序获得了更强的条件性支持；本轮没有修改噪声表。

音乐样本的音调激励不足以单独裁决 Pseudocode 105。为此通过既有外部 DME 链生成了 6 秒
14.4375 kHz 突发纯音，实际触发 27 帧 `aspx_add_harmonic`、74 次非零音调电平调用和
14 次非零左边界。配方与摘要保留在实验记录，媒体留在本地。

强音调证实了相位模型的重要性，但音调起点单位与初始相位仍耦合：直接把噪声的换算机械套到
音调会恶化结果，而增加常量相位后结果又会变化。因此未修改 `tonegen`，也未把这一项标成
已关闭。该探针仍有明显残差，不能将首轮低能量音乐对象的结论外推为“所有高频输入差异都小”。

随后另建双对象探针，同时包含上述高频纯音和 1 kHz 锚点。主低频锚点独立确认了 31 samples
的整数偏移，尺度差约 -0.000061 dB，相干性约 0.999999995，残余相位约 -0.070°。
该输入上，固定的 QMF/噪声
联合模型改善 11.35 dB；加入此前纯音实验选出的音调初相候选后改善 13.27 dB。这个候选
相当于相同单位模型下从索引 0 初始化，而 Pseudocode 105 明写的是 1；它仍是待裁决的解释，
不能仅凭误差下降直接替换明确的规范字面。

### 音调初相与幅度差可以分开观察

在不改变增益计算的条件下，分别将生成音调、噪声置零，以输出之差提取分量。两个正交音调基底
用于最小二乘诊断，参考整数偏移与输出尺度仍固定。全段拟合中，候选音调分量系数分别为
`0.998751`、`1.000532`，额外正交分量约为 `0.0003`。以末次突发中本地起点为
249856、253952、258048、262144 的四个 4096-sample 窗口为例，幅度约为
`0.99993–1.00018`，两正交基底的拟合相角在约 `±0.0043°` 内；起止过渡、低能量窗口不满足这个窄范围，
完整窗口统计均保留在记录中，没有借筛选窗口降低整段误差。

剩余大幅度差主要出现在**未依靠补偿音调重建**的段落：14.4375 kHz 主峰相位已经接近一致，
参考幅度仍约为本地的 `1.81–1.89` 倍。补偿音调占主导的末段主峰为 14.8125 kHz，双方幅度
则接近相同。编码器生成音调落在包络子带组的中心，不必等于输入纯音频率，因此不能把两个主峰
当成同一条振荡器随时间漂移。

该证据支持已有音调候选，尚未覆盖不同生成子带与奇偶组合，不能宣布 `Pseudocode 105` 已关闭。

### 预测器：Pseudocode 87 的加号不满足自身的协方差方程

按照 `Pseudocode 86`，令 `cij = Σ xi·conj(xj)`，三个抽头分别取当前、前 2、前 4 个
QMF 时隙。`Pseudocode 89` 使用加法滤波器，故未施加 chirp 时的预测残差为：

```text
r = x0 + alpha0*x1 + alpha1*x2
Σ r*conj(x1) = c01 + alpha0*c11 + alpha1*conj(c12)
```

使第一条正规方程为零，必须有：

```text
alpha0 = (-c01 - alpha1*conj(c12)) / c11
```

PDF 第 219 页却明确写了加号，修复前生产代码按它实现。`alpha1` 的公式与上述减号解相容，不能只用
“复数或系数命名约定不同”消掉这个冲突。保留原文 `2^-20` 的正则化后，它等价于只对第二抽头
加入 `lambda = |c12|²/c11 × epsilon/(1+epsilon)` 的 ridge 项。

新增 [`check_aspx_math.py`](../scripts/check_aspx_math.py)直接求增广最小二乘，不复写闭式解作为
oracle。两份有满秩复数时序的构造样本中，减号系数与独立解的最大差小于 `9e-16`，第一条正规
方程残差小于 `1e-14`；加号的残差分别约为 `64.71` 和 `30.86`。这条证据不依赖杜比输出。

在固定前轮模型后，减号使音乐后半段额外改善约 `2.36 dB`，独立音乐额外改善约 `4.83 dB`。
纯音探针第一 patch 的 chirp 为零，所以这里改系数几乎不影响 PCM；它不能解释那份探针的幅度差。
调查阶段将它列为应独立修正和验证的强候选；随后落地的单项修复见下一节，limiter 常量保持不变。

### 预平坦化：已定位影响，但没有确认参考内部算法

`Pseudocode 85` 定义 `g = 10^((mean-slope)/20)`，`Pseudocode 89` 却让幅度除以 `g`。
在拟合足够精确、功率远高于 `+1` 地板时，输出 dB 包络趋于 `2*slope-mean`，会扩大斜率。
乘以 `g` 才趋于常数 `mean`。独立构造例的原始跨度为 34 dB：除法约变成 68 dB，乘法后
只剩 `1.42e-6 dB`。原 PDF 的两处符号已核对，不能归咎于文本提取。

但**数学上的方向修正不等于参考行为已经识别**：

- 改成乘法使强纯音相对上轮模型恶化约 `1.22 dB`；在独立音乐上，与预测器减号联合的改善
  为 `14.44 dB`，仍弱于跳过预平坦化的 `18.26 dB`。
- 跳过预平坦化使带锚点纯音额外改善约 `17.06 dB`。所有实测 HF 调用都确实收到了开启的
  `preflat`，不是一个未激活分支。该旁路只是定位手段，不能据此删除生产工具。
- 在强纯音上，把 `EPSILON=1` 改为 `0.25` 或 `1e-12`、提高 `MAX_SIG_GAIN`、去掉高带
  直达分量，都不能解释主要残差。增大 boost 上限能局部补偿，取消上限却恶化；这些变体不作为
  修复方案，完整反例均留档。

为验证开关本身，按实际解析到的 128-bit 上下文唯一定位 8 个 `aspx_config`，每处只将
`preflat` 位从 1 改为 0；逐位核对确认其余数据不变。本地可完整重解 143 帧，但参考在输出
第一帧之前的那次捕获失败。将 `limiter` 位单独关闭也得到相同结果。对照实验中，原流重新捕获与旧
参考**逐位相同**；单独翻转 `interpolation` 位则正常解码全部 143 帧，输出确实改变。
该插值变体上跳过预平坦化仍额外改善约 `17.05 dB`。

**上述捕获失败的原解释已被续查撤回。** 后续重复实验发现未改码流也可能捕获失败；两种关闭
配置均已取得完整参考。preflat 开关在纯音及独立音乐上的 PCM/元数据分别逐位相同，limiter
开关则改变输出，见[剩余项报告](ASPX_REMAINING_INVESTIGATION.md)。这仍不能唯一识别参考内部
算法或把其行为当规范勘误；预平坦化的输入标度、地板和实现位置仍需区分。

## 2026-10-01：预测器符号已独立修复

生产 `tna::solve` 已将 `alpha0` 的交叉项从加法改为减法，依据和范围见
[ADR-0017](decisions/0017-correct-aspx-prediction-cross-term-sign.md)。其余诊断开关均未进入
生产代码；QMF 相位、噪声和音调游标、预平坦化、limiter 与公开 PCM 尺度保持原实现。

新的 Rust 判据直接检查复数时序的预测残差正交性，以及双音经过真实预测器/HF 生成器后的
