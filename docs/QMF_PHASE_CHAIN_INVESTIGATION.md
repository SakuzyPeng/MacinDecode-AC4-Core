# QMF 相位与跨子带搬运：独立连续链核对

日期：2026-10-18。起点：`5370688651041da92531f7a1da899d827615ff12`。

**本轮未发现生产 64 带 QMF 的相位或跨子带接线缺陷，保留生产算法。** 独立时域模型预测了
分析、搬运和合成的完整输出；一致的表示变换保持 PCM，部分变换则改变实际信号。本结论
不要求贴近 DRP，也不证明所有参考差异都无害。数值摘要见
[机器记录](experiments/qmf_phase_chain_comparison.json)。

## 判据来源

重新核对锁定的 `TS103190-1:v1.4.1:5.7.3–5.7.4`，PDF 印刷页 194–197 的 P65/P66。
生产采用的两个原点分别是 `n−0.5` 与 `n−127.5`。本轮把折叠、状态移位和多相抽取消去，
改用绝对样本时间上的 640 抽头 FIR；不读取生产调制表，也不调用参考库作为期望值。

定义 `ω_k=π(k+0.5)/64`，以及零区间之外为零的原型：

```text
a[j] = QWIN[j] · (−1)^floor(j/128), 0 ≤ j < 640

Q_p[t] = Σ_j a[j] x[64t+63−j] exp(i ω_p(j−0.5))
y[n]   = Re Σ_t Σ_k Q_k[t] a[n−64t] exp(i ω_k(n−64t−127.5)) / 64
```

负样本索引取零。中间使用声明的源／目标路由和固定 0 或 6 个 QMF 时隙延迟；不搜索
相位、尺度或最佳延迟。完整链的下一段消费上一段模型输出；另将实际生产的搬运结果交给
独立合成模型，分离分析误差的传播。分析和合成的检查点历史也分别核对。

QWIN 是两边共享的锁定数据，其 f32 字节 SHA-256 为
`870d3c80e4fe7ee368b5da1f7db487dfa84be44c4cf8c82813b78fb06a8e94a2`。
这不是对许可窗表的新审计，也不把窗表放入仓库。

## 跨子带奇偶性与解析载波

`TS103190-1:v1.4.1:5.7.6.3.1.4` / P71 的非空 patch 满足：

```text
num = sb−usb
source = sba−odd−num
target = usb
source−target = sba−sb−odd
odd = (sb−2+sba) mod 2
```

所以每一对源／目标的差均为偶数。遍历两种 master、全部 start/stop/noise/xover 与
44.1/48 kHz 选择，得到 **3,606 个合法布局、66,930 个子带路由，全部满足同奇偶**。

这条性质具有实际作用：QMF 每 64 个样本取一个时隙，当前不加逐时隙调制的复制，只能
保持相隔 `2π/64` 整数倍的频率分支。48 kHz 下，同奇偶的中心间距是 750 Hz 的整数倍，
源带内偏频可以按预期搬到目标带。奇数差的构造反控制不属于合法编码 patch；对其四分之一
带宽偏频，要求的目标频率解析系数为零，能量会出现在其它重采样像上。

载波复幅度由下式直接预测，保留实输入的正、负频率分支和重采样像：

```text
A_p(Ω) = exp(i(63Ω−ω_p/2)) Σ_j a[j] exp(i(ω_p−Ω)j)
S_k(ν) = exp(−i127.5ω_k) Σ_j a[j] exp(i(ω_k−ν)j) / 64

C(ν) = Σ_σ 0.5 exp(iσ(φ−64dΩ)) A_p(σΩ) S_k(ν) / 64
       只取 σ∈{−1,+1} 且 (ν−σΩ)64/(2π) 为整数的项
输出实余弦的复幅度 = C(ν) + conj(C(−ν))
```

`d` 是预先固定的时隙延迟，`φ` 是输入初相。没有对实际输出拟合幅相。384 个同奇偶
载波案例的最大复幅度误差为 `3.871e−8`，最大相位误差为 `2.447e−8 rad`。
这验证了声明的频移和时间原点，不能用来宣称规范的绝对相位约定是唯一可能的约定。

## 覆盖与结果

| 类别 | 案例 | 范围 |
|---|---:|---|
| 脉冲 | 512 | 全部 64 个块内位置；恒等路由及三个合法 patch；延迟 0/6 |
| 控制信号 | 48 | 零、随机原幅／缩小／放大、chirp、交替样本；相同布局与延迟 |
| 载波 | 384 | 全部 64 个源带；同奇偶目标；偏频 −93.75/0/+93.75 Hz；延迟 0/6 |
| 奇数差反控制 | 24 | 12 个源带；中心及四分之一带宽偏频；包含奇偶与频率边界 |
| 真实窗口 | 57 | tone、music AU 100、music AU 33；主路及 LFE 恒等路由、27 份实际 patch |
| 合计 | **1,025** | **6,071,936 个 PCM 样本**，含启动与完整滤波尾部 |

真实窗口沿用[宽度调查](QMF_WIDTH_INVESTIGATION.md)已固定的 Core PCM 数值表示，每份先
预热 10 个时隙，再取两个 AU，末尾追加 32 个零时隙。57 份的预热后分析结果逐位复现
既有生产 QMF 检查点。没有重新捕获 DRP，也没有更改对象 PCM 的比较尺度。

所有案例均检查完整样本、历史、有限性和结束状态，不按输出强弱筛除子带。
不同调用分段的输出逐位相同，结束分析／合成历史均归零。tone 的 19 个真实路由案例中
15 个输入为零，单独计数；这些零案例不充作非零精度证据。

前向误差界由输入幅度、算子绝对和与 `4·eps_f32` 固定计算，不依照实测残差调整。
分析、同输入合成、完整链的最大误差／对应界分别为 **0.0421、0.1842、0.0656**，
全部在界内。近零处的相对误差和 ULP 仍记录，不能用它们替代绝对误差判断。

| 非零真实窗口 | 完整链 SNR 范围 | 最大绝对误差（未将模型舍入成 f32） |
|---|---:|---:|
| tone，恒等／patch | 146.13–147.30 dB | `4.026e−12` |
| music AU 100，恒等 | 145.83–146.38 dB | `1.400e−8` |
| music AU 100，patch | 129.07–137.95 dB | `3.379e−9` |
| music AU 33，恒等／patch | 145.30–147.22 dB | `9.191e−9` |

表中 SNR 使用舍入到 f32 的独立模型，原始 f64 前向误差另行保留。弱源带和抵消会放大
相对数值残差，所以不能把最低 SNR 当作固定相位误差。本表比较生产与独立数学模型，
**不是生产与 DRP 的分数，也不是本轮修复收益**。

## 连续生产链的表示不变量

另在真实生产原语组成的连续链中插入两套任意逐带四分之一周旋转 `U(k)`。它们不是参考
库的 R(k)，只交换实虚部与符号，以避免三角舍入掩盖接线。同步变换：

```text
Q'(k) = U(k) Q(k)
T'(k,p) = U(k) T(k,p) / U(p)
noise'(k) = U(k) noise(k)
sine'(k) = U(k) sine(k)
```

跨帧原始历史与已组装 HF 尾部留在同一表示，出口逆变换后合成。TNA、chirp、已修复的
预平坦化、包络、增益、注噪、音调、组装与合并均实际执行；下一帧继续消费本地状态。
两种布局、每种四帧，覆盖 FIXVAR→VARFIX 携带、多包络、onset、音调关闭再恢复。
本组使用 limiter 开启和插值开启，不冒充全部控制组合覆盖。

恒等及两套旋转共 6 个控制，**49,152 个输出样本全部逐位一致**，QMF 输出相等，分析、
chirp、sine 与生成器游标状态也相等。五种故意遗漏则都能被检出：

| 遗漏 | PCM 位差样本数 / 8,192 | 差分 RMS / 原 RMS |
|---|---:|---:|
| 搬运系数转换 | 7,799 | 0.07166% |
| 噪声转换 | 7,269 | 0.03454% |
| 音调转换 | 5,450 | 0.00819% |
| TNA 历史表示一致性 | 5,976 | 0.00479% |
| 已组装 HF 尾部表示一致性 | 700 | 0.01251% |

这些是人为反控制的影响，不是生产中已经存在的五个缺陷。它们说明只换 QMF 两端而保留
其它算子不变，不能称为同一物理算法的无损表示调整。

## 判据验证与复现

新增普通 Rust 回归直接约束生产分析、HF 搬运和合成，使用独立 FIR 与固定期望 patch
路由；不依赖真实媒体，也不只停留在 ignored 导出入口。实际注入三个生产缺陷：分析
原点偏移、合成符号错误、读取相邻源带，均由该测试失败捕获。分析索引展开、合成加法
交换、源索引交换三种等价变体全部通过，恢复原始源码后再次通过。

[Python 检查器](../scripts/check_qmf_phase_chain.py)及其 14 个测试覆盖独立稀疏抽头、
解析频移、固定延迟、清单遗漏／重复、配方改写，以及真实文件中的中间量、历史、PCM、
摘要、截断和 NaN 破坏。文件门禁同时有未破坏的正向控制。CI 已纳入该检查器测试。

本地大样本重放使用测试入口 `replay_qmf_phase_chain`，由
`MACINAC4_QMF_CHAIN_INPUT` 指向案例文本，`MACINAC4_QMF_CHAIN_OUTPUT` 指向新输出目录；
随后运行：

```sh
python3 scripts/check_qmf_phase_chain.py MANIFEST INPUT_DIR OUTPUT_DIR --report REPORT
```

构造配方在检查器的 `synthetic_cases()` / `synthetic_input()` 中；真实窗口须保留既有来源
清单及摘要。新增大文件只写入身份核验后的 cache 卷，使用同一 target。原始矩阵、输入
媒体和许可表不入库。默认及 audio-decode 测试、两套 Clippy、格式、层审计及相关 Python
检查通过；三层 36 条 PCM 基线不更新并复验。

## 仍未解决的差异

本轮只支持当前 **64 带生产定义及其组合链自洽**。它没有把参考的 8/48 带滤波器变成与
64 带等价，也没有消除已有的带宽响应、弱源带和原生 TNA 稳定化差异。

下一项可单独审查 P105 音调初始状态与合成后的时间原点，保持本轮 QMF 和搬运规则固定。
初相 1/0 若只是两个各自完整的约定，应保留差异；只有得到条款、连续性或可观察数学性质
上的生产反例，才形成修复。参考 limiter 关闭分支的额外约束仍独立保留，不合并成相位修补。
