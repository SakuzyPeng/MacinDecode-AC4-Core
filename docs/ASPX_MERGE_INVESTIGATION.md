# 无交织时的高带合并：泄漏贡献与独立反例

日期：2026-10-20；起点 `5b711aa`。前一轮宽度传播调查已提交，本轮继续检查最后的合并。
生产数值逻辑、公共 API、CLI、开关与 PCM 基线均未改；候选只存在于测试驱动。
机器记录见 [`aspx_merge_comparison.json`](experiments/aspx_merge_comparison.json)。

后续已按 [ADR-0024](decisions/0024-select-sec-for-noninterleaved-aspx-output.md)实施最小修复。
本页保留 `5b711aa` 起点的调查、失败属性与候选结果；新生产和完整 PCM 验证见
[`aspx_merge_fix.json`](experiments/aspx_merge_fix.json)。

## 结论与证据等级

当前所有已支持的完整 A-SPX 入口，在 FIC/TIC 均未使用时仍执行全带
`Q_out = delayed(Q_in) + Y`，把原分析高带的过渡带泄漏加到已经完成包络补偿的 SEC 上。
此前用“另一条替换公式会丢掉 Y”作为默认相加的依据不完整：还可以让低带直通、高带只取 Y。

独立复核 `TS103190-1:v1.4.1:5.7.6.1`、`5.7.6.5.1`–`5.7.6.5.3` 后，**这一选择有比原先
二选一论证更充分的条件依据**。完整生产 API 的合成反例也证实现有输出包含未选择的高带项。
参考检查点提供辅助证据，并用于测量影响，不是选择该规则的唯一依据。

规范没有单独写出 FIC/TIC 都关闭时的完整分段方程，因而仍需登记为本地判读；本轮没有取得
官方勘误，也不把“与 DRP 相同”写成规范正确的证明。建议下一轮围绕这个边界做最小修复，
先于继续改变 QMF 相位或进入 A-JOC 调参。

## 独立的条件读法

锁定 Part 1 PDF 的印刷页 200–201、230–231 分别描述：

- A-SPX 出口由低带、SEC 和交织 WCC 构成；生成的 Y 来自 HF 生成和包络调整。
- 频率交织被信令选择时，WCC 才与 SEC 相加；时间交织按指定时隙替换 SEC。
- FIC/TIC 的使用分别由 present、声道与使用掩码控制，不能把专用于频率交织的加法
  无条件推广到所有高带单元。

据此提出无交织、完整 A-SPX 的边界性质：

```text
b < sbx:   Q_out[b,t] = delayed(Q_in)[b,t]
b >= sbx:  Q_out[b,t] = Y[b,t]
```

Y 在未生成的高带范围为零。该性质不会丢失 SEC，也不是把整条输出替换成原输入。
有信令的 FIC/TIC、非 A-SPX 的 LFE／SIMPLE、以及用于测时延的干通路要分别处理；不能
把这条性质直接套到通用相加原语的所有调用上。

P99 的预算为 SEC 配平，并没有计入这项未选择的 WCC 及其与 SEC 的相干交叉项。
预算本身不要求每个短区间的实测能量严格等于目标，但额外分量必须有单独的编码／选择依据。

## 不依赖参考库的生产反例

新增测试专用观察入口 `observe_noninterleaved_pipeline_merge` 实际调用完整
`frame_with_scale_factors_qmf`，包含分析、TNA、HF、包络、增益、组装和合并。

输入是幅度 16、频率 **4,078.125 Hz** 的连续纯音，频带配置
`master=false,start=0,stop=0,noise=0,xover=1`，交叉子带为 **11**（4,125 Hz 边界）。
使用已有合法双包络夹具，保持状态处理三个 2,048 样本帧，只观察第三帧。这是生产 API 的
自有构造输入，不是新编码媒体，也没有改变生产分析器或搜索延迟、增益。

低带和 SEC 都非零。第三帧高带 `Q_out − Y` 的最大实／虚分量为 **168.20998**，因此
上面的 SEC-only 性质失败。该数值是内部 QMF 幅度，不能当成归一化 PCM 峰值。
失败记录与正常观察来自同一二进制和相同输入，失败原因确为未选择的高带项进入出口。

```bash
MACINAC4_MERGE_PIPELINE_OUTPUT=/absolute/path/observation.json \
cargo test -p macindecode-ac4-decode --features audio-decode \
  observe_noninterleaved_pipeline_merge -- --ignored

# 在调查起点检查候选性质时失败；ADR-0024 修复后通过，另有普通回归强制执行同一性质。
MACINAC4_MERGE_PIPELINE_OUTPUT=/absolute/path/new-red-observation.json \
MACINAC4_MERGE_REQUIRE_SEC_ONLY=1 \
cargo test -p macindecode-ac4-decode --features audio-decode \
  observe_noninterleaved_pipeline_merge -- --ignored
```

这证明现有实现违反所提出的条件读法；该读法的规范依据由上一节单独给出，避免把期望式
放进测试后再循环宣称它已被证明。

## 固定实际检查点的合并隔离

复用已通过完整门禁的三份窗口：强纯音 AU 8、音乐 AU 100／AU 33，共 27 次主声道调用。
分析侧来自已有宽度记录；参考组装前后来自已有注噪／交织调查。两套材料的完整 38 时隙
低带逐位衔接，既有参考交织重放和捕获出口逐位相同，真实 FIC/TIC 均关闭。
本轮没有新运行参考解码器，也不计入此前失败的捕获。

先统一到生产基底和固定尺度。参考组装快照用 `Q/R64`，原分析快照用
`Q*2^23/R64`；两者原始记录的归一化层不同，低带逐位衔接保证没有额外的 ×4 或增益拟合。
固定这份 SEC，只改变最后合并选择。低带直通／高带取 Y 在 **27/27** 次当前帧出口上
逐值复现转换后的参考结果；继续全带相加留下的差分就是分析高带泄漏及 f32 加法舍入。

以下均统计当前完整 **32 个 QMF 时隙**、全部 9 路和全部高带；包络越帧区间没有重复计入。
这与按各包络 `[first,last)` 统计的结果不是同一范围。

| 固定参考 SEC | 泄漏能量／SEC 能量 | 加回泄漏后的高带总能量变化 | 泄漏位于子带 36 的比例 |
| --- | ---: | ---: | ---: |
| 强纯音 | −96.06 dB | +0.0000148% | 99.99935% |
| 音乐 AU 100 | −18.97 dB | +0.97564% | 99.99934% |
| 音乐 AU 33 | −27.92 dB | −0.21164% | 99.99180% |

加回一个分量既可能增能也可能减能，因为：

```text
||Y + L||² = ||Y||² + ||L||² + 2 Re <Y,L>
```

逐分量保留交叉项后，记账在 f32 舍入界内闭合，残余舍入项另行记录；纯音极小的净变化也受
末次加法舍入影响。仅看总能量变化，会把音乐 AU 33 的相消误当成泄漏很小。
这也解释了为什么该问题在强纯音探针上几乎不可见，却在真实音乐交叉带更明显。

## 当前本地 HF 的控制结果

复用上轮 2,268 条固定链的完整 Y，恢复对应分析输入的高带，覆盖七种分析输入、两种
插值、两种预平坦化和三种 limiter。新驱动只调用生产 `combine` 和合成器：当前策略保持
全带相加，测试端候选在推进原始全带历史后选择高带 Y。两种策略共用同一份 Y。

按默认预平坦化、插值开启和 limiter=1，D 输入的结果为：

| 当前本地 SEC | 泄漏能量／SEC 能量 | 高带总能量变化 | 泄漏能量相对 D／A 宽度所致 SEC 差分 |
| --- | ---: | ---: | ---: |
| 强纯音 | −99.02 dB | +0.00000739% | −45.62 dB |
| 音乐 AU 100 | −18.82 dB | +1.04039% | +32.90 dB |
| 音乐 AU 33 | −28.15 dB | −0.51878% | +23.24 dB |

最后一列直接比较同一基底、尺度和时隙中的两个差向量能量，没有跨阶段相减 SNR。
它表明在这两个音乐窗口里，未选择的泄漏比纯粹分析宽度造成的 SEC 差异更值得先处理；
不是对整段 DRP 残差贡献的归因。

两段受控信号加完整归零尾部的诊断 PCM 中，默认 D 输入的 12–18 kHz 差分 RMS 相对
选择式分别约为 **0.000673%、5.176%、1.593%**。它们只用于说明这项合并差异经过同一
合成器仍可观察。该序列的第二段沿用上轮的构造延续，合成初始状态为零，未进入 A-JOC；
不能写成整段对象 PCM 修复收益或听感结论。

## 门禁、限制和修复边界

新增 16 个相位边界构造，覆盖交叉子带 4／36／47／63。令固定 Y 与泄漏 L 同相、反相或
正交，直接验证增能、完全相消及零交叉项；低带使用时隙标签，避免高带选择测试掩盖低带丢失。
共有 **2,311 个固定合并案例**；独立模型逐位检查两种策略的 QMF，并用 640 抽头 FIR
核对诊断 PCM，覆盖完整尾部。13 项无媒体检查器测试包含错误延迟、遗漏低带、错交叉子带、
未选择泄漏、错交叉项、缺失／重复来源和非有限输入；原始正向与等价加法顺序均通过。

默认／audio-decode／spec-tables 回归、两套 Clippy、格式、层审计与相关 Python 检查通过。
显式 SEC-only 属性的失败单列，不能作为普通测试失败被隐去。正式二进制、三份基线和用户
文件摘要未变；本轮没有重导 36 条 PCM 基线。原始材料和大文件仍在核验身份后的 cache 卷。

下一轮最小修复应限定在**完整、活动且无交织的 A-SPX 合并**：低带按原时间轴直通，高带
使用已组装 Y，保留原始全带延迟历史。不能修改通用相加器而连带改变 LFE、SIMPLE 或诊断
干通路。修复时再验证变动交叉边界、双声道、越帧尾部、未支持交织的拒绝边界、完整对象 PCM 和
三层基线，并单独登记 ADR；QMF 相位、TNA、预平坦化、limiter 和噪声策略均不必一并改变。
